# 灰銀のレゾナンス｜v18 頭頂・後頭部の発毛密度と縮れ解消

## 要求の根拠
Android実機の顔モデル確認画面で、金髪ロングが針状・縮れ状に見え、頭頂部と後頭部が薄く見える。必要なのは「本数10万」ではなく「地肌を隠し、頭に沿って自然に垂れる髪」。

## 設計・変更
- `src/face-scalp-wig.js` の `WIG_ZONE_WEIGHTS`：クラウン12%→20%、左右後頭20%ずつ、左右襟足5.5%ずつ。前髪・側頭部も9ゾーンで保持。後頭/襟足は引き続き実頭皮の後半球頂点だけを使用。
- `actualScalpCandidates()`：クラウンを頭頂から後半球の上部まで拡張。後頭部と襟足の分布を下方へ拡大。
- `scalpShell()`：元の頭部メッシュのポリゴンと滑らかな法線をそのまま使った下地を後頭部・襟足まで拡張。四角い下地は使わず、後ろの内側髪を52→88本の細い帯状毛束へ増やす。
- `createScalpAnchoredWig()`：頭皮密着→重力落下→接触判定→最後にカット、という従来のパイプラインを維持。毛束の横方向揺れ・カール乱数を大幅に減らし、ガイドを3回低域平滑化する。頭皮の本当の毛根とサロンカットの毛先は固定。
- `writeGeometry()`：頭頂・後頭部の毛束を少し厚くし、過剰な髪色・毛先ハイライトのばらつきを抑制。髪型ID/センター分け/ヅラ単独GLBを書き出す管理は変更しない。
- `update()`：20Hzガイド髪の風の揺れを弱くし、未シミュレーション毛束の高速な微振動も減少。毛先カット制約・顔/首/肩への衝突判定は保持。

## 受入検証
- `qa/independent-face-masters.test.mjs`：頭頂部・後頭部の毛根配分、後頭の実3D後半球根元、88本の細い内側毛束、長さ制約、ガイドが有限値かどうかを検査。
- `qa/independent-face-masters-browser.cjs`：女性の正面・側面・後頭部、独立ヅラGLB、保存顔・アイライン・ズーム・男女GLBを検証。実機の美術評価は別途必要。
- 戦闘、町、胴体、男女の顔標準値、眼球、唇の造形は改変しない。見た目が未完成の場合は自動テスト成功でも完成とは扱わない。
