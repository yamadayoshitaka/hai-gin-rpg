# 灰銀のレゾナンス：住宅設計書 v28.0

## 設計目的
従来の継ぎ足し家具・仕切り配置を廃止し、1つの間取り定義から壁・開口・ドア・家具・当たり判定を生成する。室内は45度刻みで回るタクティカル視点。廊下は全区画への共通アクセス。

## 寸法と縮尺
通常住宅の室内座標は幅42×奥行39。ゲーム内の1単位は概ね0.25m相当で、約10.5m×9.75mのモデルハウスを意図する（実際の物理メートルではない）。特別な建物は幅54×奥行48の比例拡大版。床高0、壁高8.65。室内中央を(0,0)、北奥がz負、玄関が南正面z正。

## 1階 平面図（北が上）
```
                北 / z-
┌────────────────────┬── 廊下 ──┬────────────────────┐
│ 洗面・浴室・収納    │          │ 客間・多目的室     │
│ 洗面台・収納棚      │   共通   │ ベッド・チェスト   │
│         ドア →      │          │      ← ドア        │
├────────────────────┤          ├────────────────────┤
│ リビング           │          │ ダイニング・台所   │
│ ソファ・低卓・TV台  │  動線    │ 食卓・キッチン     │
│         ドア →      │          │      ← ドア        │
│ 左奥に階段         │          │                    │
└────────────────────┴── 玄関 ──┴────────────────────┘
                南 / z+
```
廊下の半幅は通常住宅4.8単位、約2.4m幅を確保。南北につながり、家具は置かない。左右の各2室と廊下の境界には4か所の開閉扉。中央の前後に連続した壁があって通路を塞ぐことはない。玄関は南側中央。

```
│ 主寝室             │          │ 子供部屋           │
│ ダブルベッド・棚    │          │ シングルベッド・机 │
│         ドア →      │          │      ← ドア        │

```
階段位置は左側の奥寄り。2階の平面モデルは従来どおり階層切替方式で、完全に地続きの3D階段は別工程。

## 衝突・扉仕様
壁・家具は描画と同じ定義から矩形衝突体を登録。幅3.4～3.8単位の扉は閉扉時のみ衝突体を加える。扉の開閉は「話す・調べる」、近接3.5単位以内。扉・壁は木枠付き。窓側の家具配置、廊下・ドア前への家具配置は禁止する。

## 再現方針
通常の居住系室内は、この設計図専用グループに描画を差し替える。旧室内の重複する壁・家具は非表示にし、NPCと照明は保持。商店・教会・宿など専用室内は既存を保持して段階移行。v28.0は現行ブラウザー版の模型であり、建築確認用の実施設計図ではない。
