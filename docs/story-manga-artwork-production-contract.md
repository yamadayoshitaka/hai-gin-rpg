# 灰銀のレゾナンス — 漫画原画・一ステージ単位の制作契約（厳守）

適用: 第1章〜第20章、男性・女性版、イベント前・勝利・敗北・ゲームオーバー・町イベント後、全シーン。

## 絶対禁止 — 台本と原画の整合性

1. 原画の中に **数字（「01」「02」「04」等）、コマ番号、文字、セリフ、字幕、見出し、ふりがな、UI、透かし、装飾バナー、フレーム番号、ウェブサイトURL** を描かない。
2. 画像生成器へ **確認画面・ダッシュボード・広告ポスター・制作報告・PR番号** を描かせない。例外として、**台本に沿った2列×最大10コマの連続ポスター＝漫画原画シート** は構図確認のため作成してよい。商用ポスターや仕様図を原画と混同しない。
3. **最初に台本に沿った全パターンの連続ポスターで時系列を確認**し、次に1コマずつ高精細16:9単独原画を完成させる。ポスターの単純な切り抜き・引き伸ばしが個別原画の画質基準に達していなければ再描画し、合格させない。個別原画と保管用シートを両方保存する。
4. 男性主人公の絵を女性版の主人公が必要な場面に流用しない（逆も同じ）。性別を変える場合は **主人公の見た目だけ** を差し替え、他の人物の身元・舞台・事件・構図を維持する。主人公が登場しない景観・物証は同一の画を使ってもよいが、登録先は男女別にする。
5. シナリオと一致しない場面、別の勝敗・主人公戦死・別のステージの絵を代わりに表示しない。
6. 全シーンを確認する前に「完成」「デプロイ済み」「品質承認済み」と報告しない。
7. 生成画像に含まれるデプロイ完了やURL等の文字を、実際の実行結果として扱わない。

## 1ステージ完了の条件

1. `comicForStage(stage, phase, {protagonistGender})` の **全コマのID、担当人物、場面、音声の読み** を先に確定する。
2. 全分岐の連続ポスターを用意し、男性版の各場面の独立高精細原画を作成。利用予定の既存原画は台本・人物・勝敗を確認したものだけ登録し、不足分を新規制作する。次に同じ構図で主人公だけを女性へ置換し、女性版の独立原画を作成する。性別を変えてはいけない固定キャラクター（リュシア、ガラン、イリス等）は維持。
3. 原画ごとに、文字・数字・枠・UI・画面内の透かし・性別混入を目視で確認。該当するものは **却下して再作成**。
4. `panels/{shotId}-{edition}-{gender}.webp` の版別保存を原則とし、既存の旧命名も保持する。同じ画像から組み立てた保管用シートを別保存。**新制作は個別1536x864以上・16:9**、2列×N行のポスターは3072x(864×N)以上が推奨。サイト表示では登録済み単独原画を優先し、低解像度切出しを合格品質と見なさない。
5. 男性・女性、すべてのイベント分岐についてファイル存在・WebP正常性・実IDとの一致・前後/勝敗の独立性を検証。
6. **各個別画像を合格基準画像と並べて表示**し、画質・人物同一性・構図・勝敗・画像内文字・流用の妥当性を検品する。実ゲーム（タイトル/町/戦闘前/戦闘後）でセリフごとに1枚だけ表示されることを検証し、mainへコミット・マージ後、GitHub Pagesの成功を確認する。
7. 人間が未承認の場合は「初稿」と明記し、品質承認を作業完了と混同しない。ステージ全版合格後に限り次ステージへ進む。制作フローと合格基準の詳説は `docs/story-stage-poster-production-manifest-v2.md`。

## 生成プロンプトの冒頭に必ず付与する制約

> これはゲーム内でセリフと別表示する **16:9の単独の一枚絵** です。絵の中に文字、数字、番号、コマ割り、吹き出し、字幕、ロゴ、UI、枠、URL、ウォーターマークを一切描かないこと。シナリオで指定された出来事だけを描くこと。人物ID・役職・衣装・髪色・顔つきの一貫性を維持すること。男性版を女性版にするときは主人公だけを女性軍師へ置換し、他の人物と場面構成は維持すること。完成報告やゲーム画面を描かないこと。

この制約は生成器の遵守を保証するものではない。画像登録前の検品で必ず再確認すること。
## ステージ2・3以降の無料バッチ

`node scripts/prepare-story-stage-posters.mjs --start c01-s02 --count 2` で男女・全結果版の台本と画像不足、再利用候補、品質参照画像を列挙する。実画像生成が実施されない場合は `MISSING` と表示し、生成済みに偽装しない。自動バッチは追加有料APIを呼ばず、既存の無料リソースだけを用いる。

**注意：** 画像生成サービスが返した完成報告風の画像や、文字入り制作表は漫画原画ではないので、必ず却下する。
