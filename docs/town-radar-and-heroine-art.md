# レヴナ町レーダー・施設直接入室・男女主人公ストーリー原画

2026-11-11 / 実装担当向け仕様・QA。

## 町レーダー
- 本編の `town-hub.html` に常時表示される小型俯瞰レーダーを追加。元の「全体マップ」は廃止しない。
- 描画の元画像は既存の `tactics-wireframe.html` 3D町エンジンが生成する `hai-gin-town-overview`。新しい地図の手書き座標・別マップ・別の3D世界は作らない。
- 3Dエンジンから返る `hai-gin-town-stage-ready` の施設ID・座標を使用。武具屋・道具屋・宿屋・酒場・教会・王城の位置ピンは、レーダーと全体マップの両方で選択可能。
- ピン選択は `hai-gin-town-enter-facility` をエンジンへ送信。建物IDを既存の `townServices` 登録と照合し、正しい `townEnterBuilding(building)` の室内へ直接入る。
- 既に建物にいる時は既存の `townLeaveBuilding()` を経由して移動。UIは子エンジンの `hai-gin-town-entered` 応答後に閉じるため、ロード・誤ID・未準備状態で入室成功と表示しない。
- レーダー上の青いピンは軍師の移動メッセージに追従。レーダーの上部をタップするとフルマップを開ける。
- 現行の家の扉、店主との会話、各店舗、戦闘の当たり判定、3D人物モデルは変更しない。

## 男女主人公の原画
- 新規ゲームで選んだ `game.campaign.commander.gender` を `storyStageContext` → `mangaForStage` → `applyCinematicImage` へ渡し、全200ステージの1,400コマで性別による画像選択を可能にする。
- 男性：従来の `c01-s01-m01.webp` などの個別場面画像を優先。
- 女性：`c01-s01-m01-female.webp` のような **別画像** を優先。女性版が未登録のときは男性主人公の写真を表示せず、ストーリーキャラの絵と地形で構成される従来の漫画SVGを残す（低品質ではあるが誤った男性主人公表示を防ぐ）。
- 主人公の性別がまだ未選択のタイトル序章では性別未確定を渡し、男女どちらかの顔を確定させない。
- 第1章の `m5`（王印・書状だけ）は顔の出ないジェンダー非依存の検証済み画像として共有。性別に依存する他の画像は勝手に流用しない。
- 初回の女性用暫定主人公マスター：`assets/story/characters/commander/female-master.webp`。
- 初回の女性用独立原画：`assets/story/panels/c01-s01-m01-female.webp`。これは第1章の王都到着を描いた **暫定原画1枚**。残りの女性用描き起こしと3Dモデル最終仕様への整合は未完了であり、全コマ女性原画完成とは記載しない。
- 既存の男性原画7枚、20人のNPCマスター、台詞、VOICEVOX音声はそのまま保存する。新しい有料APIは呼び出さない。

## QA
`node qa/town-radar-gender-art.test.mjs`、`node qa/story-cinematic-audio.test.mjs`。

手動：
1. 町をロード → 上部左側に小レーダー、位置ピンが見える。
2. レーダーの王城・教会等のピンを選択 → 3D室内に入る → 店主／侍従との会話と施設UIが使える。
3. 建物から出る → レーダーに現在位置が表示される。全体マップでも同じ動作。
4. 男性データと女性データをそれぞれ新規作成 → 女性なら第1章の到着絵が女性になる。他の未登録原画でも男性の軍師が突然映らない。
5. 物語メンテナンスの男女切り替えから同じコマを比較できる。
6. 町／建物の衝突、町の初回イベント、50対50と1,000対1,000戦闘の回帰を確認する。
