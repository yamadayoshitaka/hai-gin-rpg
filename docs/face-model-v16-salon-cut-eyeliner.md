# 顔モデル v16 — 頭皮密着サロンカット・アイライン連動

対象: `src/face-scalp-wig.js`, `src/face-feature-meshes.js`。v15の保存顔（顎5・鼻穴2・鼻筋2.5）、メイク・ズーム・GLB・男女独立モデルを変更しない。

## 目標と症状

v15実機画面では頭頂部と側頭部が風船のように膨らみ、毛束が扇状に飛び出し、前髪と側面のカット面が直線的。後頭部には毛根が存在しても、表面を覆う自然な流れが見えない。目角度スライダーを動かすとアイラインが上下まぶたから浮く／途切れる。

## プロシージャル髪生成（`createScalpAnchoredWig`）

1. **真の頭皮根元**: 頭部メッシュの実頂点と法線を使用。頭頂12%、左右前髪各4%、左右側面各13%、左右後頭各21%、左右襟足各6%。後頭・襟足は`z < 後頭中心`の実頂点のみ。前方頂点で代用せず不正なメッシュは失敗として検知。
2. **頭皮密着**: `createHeadEnvelope`で40×80の頭皮半径場を生成。単一頂点の最大半径ではなく、各セルの72パーセンタイル半径と、角度・高さの加重補間・３回の平滑化を使用。頭部外側への余裕を小さくし、根元から滑らかに接続。
3. **毛束の厚み**: 頭皮近傍と中間の毛束を太くし、毛先の最後15%だけ細くする。標準表示1,440束を維持し、10万本の個別物理は行わない。色付き連続頭皮メッシュで地肌を隠す。
4. **美容師カット**: 前髪は眉付近に自然な長さのばらつき。顔に近い側頭部は短め、後頭部と襟足は長め。毛先は黄金角の位相による微小なランダム風のポイントカットで揃いすぎを避ける。横方向の扇状スパイクを抑え、髪の流れを下向きに保つ。
5. **軽量化**: 外形場はWeakMapにキャッシュ。見た目の1,440束のうち約320束のみ20Hzで物理計算する。

## アイライン（`refitEyelinerToLids`）

上下アイラインは各まぶたの子メッシュで、`updateFaceFeatureAngles()`の度にまぶたの28×4グリッドを再サンプリングし、約116点/ラインの3D頂点座標と上下の目頭・目尻接続を再調整。マテリアルに`polygonOffset`と描画順を与え、回転時のZ-fightingを防止。眼球、まぶた、眉、アイラインは同一眼窩回転ジョイントを維持する。

## 回帰受入

- ９領域それぞれの毛根が実頭皮に存在し、後頭・襟足の毛根が必ず後半球に存在する。
- 後頭毛束は後ろへ伸び、毛先高さにばらつきがある。前髪が眉より大きく下へ落ちない。
- `eyeAngle=-20/0/+20`で４本のアイラインの実頂点が対応まぶたから離れない。正面の各角度をスクリーンショット保存する。
- 正面・側面・後頭の描画、髪付き女性GLB、髪なし男女GLB、ズーム、保存スライダー、口紅高速更新が引き続き成功する。
- 最終の美術品質は実機の比較で判断する。単体・WebGL/GLBテスト成功だけでは美術的な完成宣言を行わない。
