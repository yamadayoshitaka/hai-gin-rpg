# 剣士マスター001 — 統合制作工程と検証結果

対象ページ：`master-swordsman-prototype.html`（ゲームメニュー→「剣士マスター001」）、ソース：`src/master-swordsman-assembly.js`。

## 今回実装済み（**鑑賞用1体**）
- [x] **高品質マスターソース**：Blender Studio CC0の男性人体GLB（元の形状11,674頂点）とリアル頭部GLB（5,134元頂点）を保持。原本の編集・ポリゴン削減はしない。
- [x] **顔・骨格の位置合わせ**：体格（1.69m）と頭部を実メッシュのAABBから計測し、元人体の頭をマテリアルのクリッピングで非表示にした上で別の詳細頭部を重ねる。継ぎ目は今後の人手審査対象。
- [x] **顔の立体形状差別化**：顎幅、頬骨、鼻の突出、鼻幅、口幅、顎先、眉骨の7種の実メッシュ形状を制御。剣士／魔法使い／忍者のサンプル比較に対応。
- [x] **実際の衣装素材**：Makehuman-2 Viking CC0（上衣、ズボン、ブーツ、髪など）の元OBJ→GLBを使用。元の7枚のDiffuse画像／UVは保持（実測Normal/Roughnessではない）。金属・革の表面物性は見た目を確認するための仮値。
- [x] **衣装内側の人体マスク**：元ソースを変更せずに、衣装のAABB内に入る中心部の体表三角形だけをプレビュー側で非表示。腕と手が消えないように身体中心からの距離で制限。
- [x] **CC BYの髪素材**：既存のVincent Freelance髪型13の高密度版を頭部へフィットし、ソースの作者とライセンスを明記。元の目立つ疎い頭頂髪は重ねない。
- [x] **目の検証**：BlenderソースのSclera.L/Rの実位置を検出し、2つのまぶたプロキシを開閉できるようにする。実際の顔FACS/眼窩スキン連動はまだ未完。
- [x] **剣士の識別**：金属の肩甲・仮の剣を表示。これは自前の試験用3D部品であり、物理把持やダメージアニメーション未対応。
- [x] **ブラウザで鑑賞**：全身・顔アップ・横・背面、職業別造形、開閉眼、実衣装ON/OFF、髪ON/OFF。
- [x] **回帰テスト**：Nodeのソース位置合わせ単体テスト + Playwright/WebGLでの画像差分（顔、眼、衣装）。本番の戦闘にはまだ適用しない。
