# 全身アクション工房 v3.0 設計
顔GLBをビューアーから一時IndexedDBへ転送し、全身工房で読み込む。元GLBは変更しない。R20/E系のR8_SKINを持つ頭部のみ対応し、非対応の場合は理由を明示して人体単体を維持する。
人体は旧65骨衣装モデルを廃止し、既存のMakeHuman HM08 CC0男女×子供・成人・高齢163骨を使用する。これは新規人体造形ではなく人体ベースの刷新である。9年代に対し3基準形状を選び、中間年代は身長・体格・顔の局所変形で補う。4体型は胴・腕・脚・顔を別々に変形する。試験服は頂点色による一体表現。
顔は基準の頂点を保存し、選択のたび基準から頬・顎・目周辺・首を変形する。モーフ差分は基準から再計算する。性別変更では別の人体を選び、取り込んだ顔の性別形状は近似変形する（別の正式男女顔がある場合は差し替え推奨）。元の目鼻口・髪・表情資産を保持する。首は断面を計測し、人体の頭部を除去して顔を骨格へ装着する。完全な連続トポロジー結合・接触物理は対象外。
動作は独自v2の設計を維持し、163骨へ変換する。年齢・体型・骨長に応じ速度、歩幅、支持期、手足の可動域を変える。性別のみで能力を決めず、人体の寸法差を反映する。
テストは全男女・3年代の骨格、顔読み込み・首の接続・年代/体型の再計算、歩行、指の開閉、物体の保持をブラウザで検証する。実機、首の外観、精密年齢再現は別途評価する。
