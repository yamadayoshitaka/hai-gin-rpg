# 人間型モデルの衣装・髪位置と初期カメラ改善（2026-11-14）

## 受領した実機画像と症状
ユーザー提供の14:47の縦画面スクリーンショットは、魔物図鑑の **m034 血月ヴァンパイア**、v4.5.10、idle・約22FPS・28,890三角形の状態。上から覗いたような構図で、黒い外套が頭と肩の周囲に大きく広がり、頭頂に肌らしき光沢部分が露出している。衣服・身体の位置関係が分かりづらく、モデルの全身も視認しにくい。画像だけではすべての衣装が実際に貫通していると断定できない。

## 今回の原因調査と修正
1. **m034の外套**: `src/monster-gothic-sculpt.js` で、外側の幅.40・丈1.04と、ほぼ同じZ面の裏地幅.35・丈.95が重なり、さらに高い位置に重複の独立カラーを生成していた。外套を幅.29・丈.77、裏地を幅.27・丈.73に抑え、肩より後ろ／下へ配置する。重複カラーは廃止し、先行PR #350のフィット襟を使用する。胴部の血色のある裏地は保持する。
2. **13種類の衣装寸法**: `src/monster-regal-garments.js` の首・肩ヨークの上端を約.07〜.10m下げ、実人物の顔や首に飛び出すリングを抑制する。腰下のヴァンパイアのスカートフレアを.30から.19へ減少。骨の左右上腕付け根の間隔から衣装の幅を計算し、当該**モンスター個体インスタンスの衣装メッシュだけ**にX/Z補正を掛ける（取り付け元・GLB・共通骨格は維持）。
3. **頭頂部の髪**: 元のGLBのHeadボーンのローカル上方向がモデルの上方向と一致する保証はない。頭ボーンに従属する髪アンカーを「モデル上方向」に補正し、スキニング後の頭表面も*そのアンカーの座標*で採寸する。頭部回転へ追従しつつ、横向きのボーン座標によるズラ化・頭頂露出を防ぐ。90度回転したHeadを使う回帰テストを追加。
4. **人間型の図鑑カメラ**: 初期視点と「全身」リセットは人物正面（+Z）寄り。人間型16種のみ、ほぼ垂直な真上までの回転を制限する。獣型にはこのカメラ制限を掛けない。

**留保**: これらは形状の根本原因に対する座標・寸法調整であり、スクリーンショットに映ったすべての症状が消えたと実機で証明するものではない。アニメーション中の肩の食い込み、髪の剛体・揺れ、光沢、顔の美しさ、実Android FPSは追加の正面/横/後ろ/攻撃動作スクリーンショットと実機検証が必要。費用が発生する画像APIは使用していない。
