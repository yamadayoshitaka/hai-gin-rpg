# 灰銀のレゾナンス：戦況別対応号令 全体マトリクス（初版）

## 変更不可の設計境界

- **勝敗は共通判定**：固有目標達成 **または敵軍殲滅**。敵と味方の勝利条件は対称／対向で勝者が必ず一方に決まる
- **軍団作戦**：開戦前に複数隊の役割と移動ルート（高所・階段・屋上・橋・迂回路・飛行着地点）を設定し、開戦後は固定
- **対応号令**：戦闘中の敵の行動を観測して、部隊のジョブに合う複数案を表示する。一時的な攻撃・守備・支援・既存のオブジェクト任務のみ。**移動ルートは対応号令に含めない**
- **発令頻度**：1回目発令後60秒、2回目90秒、3回目120秒、4回目150秒、5回目以降180秒。戦闘内時計を使い軍団全体で共有。自動行動・未確定のキャンセル・失敗指示は加算しない
- **実装の線引き**：既存の戦闘APIへ接続できる号令だけボタンを有効化。飛空召喚獣による高所救助・先駆け・迎撃の専用AIは**未実装**として選択不可（通常の召喚獣騎乗と屋上移動は既存）

## 現在の分類・登録数

戦況 **67種類／8分類**、対処コマンド **20種類**。組み合わせはジョブ・オブジェクト存否・軍師生存・危険度によってさらに変化する。下表は「主要な戦闘状況」の網羅定義であり、未知の全事象まで検知可能という意味ではない。

## 実行系と優先度

| 種類 | 号令実行 | ルート変更 |
|---|---|---|
| 基本号令 | 突撃・守備・待機・退却 | しない |
| 目標集中 | 既存の敵部隊・敵主将への攻撃任務 | しない（既存の進路検索に従う） |
| 魔法使い | 敵建物・樹木の焼却、火災消火、修復 | しない |
| 忍者・盗賊 | 障害破壊・橋破壊・解錠・施錠 | しない |
| 僧侶 | 回復要請（負傷者と支援元の存在を確認） | しない |
| 召喚獣 | 救助、独立先駆け、空中迎撃の候補定義のみ | 作戦側で管理・専用AI実装まで発令不可 |

### 検出についての重要事項

「自動」は現在の隊列モード・生存数・座標・HP/MP・登録施設・召喚獣などから判定できる信号。「信号待ち」は状態異常、煙、天候、崩落危険など既存エンジンから確かなイベントが届いて初めて候補化するもの。推定だけで危険を表示しない。

### 将来追加する場合

`src/battle-countermeasure-situation-matrix.js` に状況ID・信号・対応号令のリストを登録し、号令の対象検証・必要ジョブ・実装状態を指定する。専用処理が未完成なら `status:'planned'` として無効表示する。ルートや経路探索は `src/battle-tactics-preset-policy.js` 側で管理し、戦闘中の号令とは混ぜない。
