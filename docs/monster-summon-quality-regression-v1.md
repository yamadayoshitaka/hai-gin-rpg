# 灰銀のレゾナンス：モンスター・召喚獣 3D品質回帰修正指示書 v1.0
更新日：2026-11-13

## 目的と境界
- 対象：モンスター50種の固有メッシュ／関節／アクション、召喚獣の別系統モデルを回帰対象とする。
- 最優先：m032「古墓のミイラ」と人型モンスターの造形、ジャンプ・着地の運動。
- **主人公・仲間の共有人間メッシュ／フェイス／GLB資産は編集しない**。`src/monster-geometry.js` の専用プロシージャル彫刻を改善し、別系統の既存人間モーションの改変を避ける。
- 段階的な実装と証拠を区別する。プロシージャル関節の修正を「全50体のウェイトスキニング完成」と扱わない。
- 既存の約束：50種、10系統、すべての既存アクション、遠近LOD、モンスター素材管理、50対50/1000対1000戦闘、Androidの描画予算。

## 実装ルール
1. それぞれの形状は幾何学的な**根元/中間/先端**を持ち、接続部を親メッシュへ十分潜らせる。浮かせた別球体の寄せ集めにしない。
2. 動く部品は**親子ピボット**の下に配置。肘・膝を曲げる時、先端の布・爪・毛も同じ関節を追従する。
3. 静止した絵を貼る代わりに実3Dモデル／必要に応じてリボンメッシュを使う。UV、法線、有限頂点、レンダリング負荷を確認する。
4. ジャンプは4フェーズ。滑らかな時間関数で根元変位と各部位の遅延をつける。完了後は状態を待機に戻す。死亡状態は再アニメーションさせない。
5. カタログ／人間キャラの共有顔・髪・リグ・GLBの変更を避ける。機能が共通ファイルを必要とする場合は競合回避のため独立のモンスター実装にする。
6. source / high / low を維持し、highでは質感と形状を上げ、lowでは省略。1000対1000向けGPUインスタンス予算を崩さない。
7. PRに**コード差分、再現手順、アクション段階テスト、CIログ、近景/遠景比較**を記録する。未測定FPSを「改善済み」と表現しない。

## 研究根拠
- Khronos glTF 2.0: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html （JOINTS_0 / WEIGHTS_0 / bind matrices）。
- Three.js Skeleton / SkinnedMesh: https://threejs.org/docs/#api/en/objects/SkinnedMesh
- Blender Manual（Armature/Skinning）: https://docs.blender.org/manual/en/latest/animation/armatures/skinning/index.html
- 個別の犬・猫・鳥・節足動物の運動文献：`src/monster-anatomy-reference.js` を正本とする。
