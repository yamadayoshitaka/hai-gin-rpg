# 人モデル v64 — 髪型・顔・表情・キャラクター台帳 回帰仕様

## 目的とスコープ
実機画像で確認された、頭頂の黒い点・細い針のような前髪・顔から離れたサイドポニー、顔の位置と合わない陰影線を修正する。顔モデルの元GLB、人物のID、衣装・戦闘の実モデル、保存済みの1〜10番の完成顔は変更しない。

## 髪型の造形
- `src/face-wig-styles.js` と `src/face-hair-groom-v50.js` を「名称・毛流れ・長さ・結び方の正」とする。定義は実ジオメトリ生成で検証し、ラベルだけを切り替えた髪型は禁止。
- サイドポニーは実頭皮頂点を計測して結び目の位置を決め、頭頂・側頭部の7つの供給毛束→頭皮上の結び目→14個の先細り長髪束へ連続させる。外接箱から頭後方に単独の棒を生成してはならない。
- 結び束は実曲線の先細りチューブ、頭髪は実頭皮に沿った不透明の束とする。頭皮三角形の一部が生え際ライン以下となっても、元の三角形を丸ごと破棄せず、境界面で切り、法線を補間する。
- 色は現在の16色プリセットを尊重。自然な毛流れの個体差を表現するが、根元の色を極端に暗くして黒い点・穴に見せない。
- 四方・後頭部・頭頂部を確認。髪の根元浮き、髪の貫通、別オブジェクトの孤立、サイドポニーの結び目からの途切れは不合格。

## 顔の陰影・年齢表現
- 目元影は顔全幅の±0.35付近にある実際の眼窩へ追従させ、鼻筋へ誤ってシワを描かない。
- 20代以下の年齢別シワ係数は 0 のまま固定。30代以降は必要な量だけ、柔らかい皮膚の凹凸で表現する。狭いノコギリ状線を上から貼り付けない。
- 瞳・メイク・顔のオリジナルのUV・頂点は再利用し、ユーザーが保存した顔・髪の設定を守る。

## 顔タイプ / 表情 / 登場人物管理
- 既存10種の完成顔IDを残して男女各16種の完成顔とし、メイク・目・鼻・口の組み合わせは `PART_CATALOG` の実設定値に紐付ける。
- 既存10感情表現＋12種類=22種類。各表情は眉、まぶた、口角、開口、頬の動きの独立した数値として持つ。瞬き・口パクは継続。
- `character-face-catalog.html` に顔32、髪型、表情22、既存主要キャラ・NPCを表示する。ID／名前・性別・職業／年代・顔／髪を比較し、リンクから真の3D編集画面へ移動する。
- 個人用の顔タイプ名と分類をブラウザへ保存でき、JSON出入可能。ただし GitHub 共通マスタを変更したと誤認させない。
- カタログの埋込3Dプレビューは読み取り専用。顔保存データを書き換えない。

## 回帰判定
1. `node --test qa/human-v64-catalog-and-hair.test.mjs`：ID、名称、各フェイスのパーツ対応、全キャラの髪型実在、22種類の固有表情、サイドポニーの頭皮接続、20代シワゼロ。
2. `node --test qa/independent-face-masters.test.mjs`：旧実顔・旧髪型の回帰。
3. `node qa/human-v64-catalog-browser.cjs`：モバイルサイズの実Chromium/WebGLで女性顔01/16、男性顔16、女性サイドポニーの正面／横、決意表情を撮影。
4. 旧ゲームの装備・着衣／脱衣、首の接続、キャラクターの衣装メッシュ、戦闘CIを保持。
5. PRの全CIが成功し、実3Dの顔・頭頂・結び目・サイド髪が十分自然であることを目視確認するまでは、mainへのマージと本番デプロイはしない。

## 未完了と今後の品質課題
現時点の改修は既存のThree.jsプロシージャル頭髪の改善であり、商用の高精度ストランドヘアやデザイナーが監修した新規フォトリアル頭部アセットを作成・差し替えたものではない。FF13級の見た目を品質保証するものではない。3D描画の定量結果と画面レビューを区別する。
