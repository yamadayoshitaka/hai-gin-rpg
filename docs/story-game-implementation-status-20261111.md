# ストーリー20章のゲーム実装・音声・原画連携 状況（2026-11-11）

## この差分で実装するもの
- `story-maintenance.html`：20章の分岐、200ステージ、7コマ、人物20名、所属国と適用話者のプレビュー、現行ゲーム導線を表示する読み取り専用の保守ページ。
- `game.html`、`town-hub.html`、`world-map.html`、`dev-menu.html` から保守画面へ移動できる入口。
- `src/story-narrative-flow.js`：三国と記録院・鐘守・中立森守、20人の人物ID、第13章の4協力ルート、第20章の3エンディング、章ごとの出撃方針の状態モデル。
- `world-map.html`：各章の第5ステージの方針選択。第13章の町イベント後に、条件を満たす協力先を選択。第20章の決戦勝利後に結末を選択。
- `src/core-battle-bridge.js`：ストーリーの協力先・方針・敵の名称を出撃リクエストに記録。3D戦闘本体のモデル・当たり判定・操作系は変更しない。
- `src/story-stage-manga.js`・`town-hub.html`：第13章以降の選択ルートを漫画冒頭の台詞・状況へ反映。章・コマIDは保つ。
- 人物設定の衝突を修正（エド：元騎士の記録官、フィオ：召喚技術を研究する工兵長、記録院長：ヴェス、ノエル：中立）。
- `src/story-voice-director.js`：キャラID→意図するVOICEVOX話者、速度・ピッチを固定。収録済みの**該当台詞そのもの**があれば音声を優先し、未収録なら端末の日本語読み上げで再生する。既存の章ナレーションと戦闘音声は維持。
- `scripts/generate-story-panel-voicevox.mjs`：既設のVOICEVOXエンジンが使用できる環境で、章を指定してコマの音声WAVを生成し、既存マニフェストへ追加するユーティリティ。
- `src/story-cinematic-assets.js`：`assets/story/panels/c01-s01-m01.webp` といった専用の1コマ絵があれば最優先。未配置なら既存のキャラマスター＋章画の合成、およびSVGにフォールバック。既存イラストを破棄しない。
- `qa/story-flow-maintenance.test.mjs` / `npm run test:story-flow`：20章、200ステージ、1400コマ、4協力ルート、人物と話者、3エンディング、画面の導線を検証。

## 現行の本編導線
1. タイトル：`game.html` → 新規開始／続きから、最初のチュートリアル。
2. 町：`town-hub.html` → 漫画イベント、買い物、編成、セーブ。
3. 世界地図：`world-map.html` → 章、ステージ、漫画、出撃、分岐。
4. 戦闘：`tactics-wireframe.html?storyBattle=1&core=1&stage=...` → 世界地図から作成した出撃要求のある場合のみ。本編以外の直リンクはCPUテスト専用。
5. 保守：`story-maintenance.html` → ステージのロックと無関係に全章を閲覧できる。**セーブは編集しない**。
6. 旧 `story-mode.html` と `dev-menu.html` 内の旧エントリは比較・開発確認用であり、本編の正規導線ではない。

## 実装済みと未完了を区別する
- **実装済み**：国家・人物ID、章ごとの物語方針の記録、協力ルートの選択、3結末の記録、UIと章漫画の文脈、既存音声＋端末読み上げの切替。
- **未完了**：専用の高品質 `*.webp` 各コマの本番登録（全1400枚）、各コマの新規VOICEVOX `*.wav` の生成・配備、分岐に応じた3D軍旗／NPC／援軍／勝利条件の全面的な書き換え。
- **セーブ**：町のみ本保存の方針を維持。世界地図内ではセッションへ先に記録し、町の教会で本保存する。
- **出撃方針**：戦闘結果と結びついた履歴であり、戦闘に「住民救出数」が無い場合に救出人数を捏造しない。
- **3Dモデル**：別工程で制作中。今回の変更ではキャラID・所属・原画・話者だけを定義し、3D人型モデルの形状やアニメーションに触れない。

## 画像制作者への連携
- キャラID：`src/story-cinematic.js`。国と政治的立場：`src/story-narrative-flow.js`。
- 第1章冒頭の順序：`c01-s01-m1` 王都到着／m2 リュシアの挨拶／m3 ガランの紹介／m4 イリスと死者名簿／m5 先王の王印／m6 ガランの助言／m7 町を探索へ。
- 画像パス：`assets/story/panels/c01-s01-m01.webp` 等。背景だけでなく人物・手掛かり・場所が台詞に一致する**1場面につき1枚の完成絵**を納品すること。
- キャラマスターは1人1ID。主人公の外見は別工程の3Dモデルに合わせて後で確定する。
- 画像パスの優先順位：専用コマ原画→現在の高品質章背景＋人物合成→既存SVG。
- 未完成の元画像は残し、照合してから差し替えること。

## 音声収録の使い方
- 既存の音声リスト：`audio/voicevox/manifest.json`。章ナレーション20件と戦闘ボイスは既設資産として維持。
- 各コマのVOICEVOX音声を生成するには、VOICEVOXエンジンを起動した環境で次を実行する（生成済みだとは主張しない）。

```sh
VOICEVOX_URL=http://127.0.0.1:50021 node scripts/generate-story-panel-voicevox.mjs --chapter 1
```

- 生成後は更新した `audio/voicevox/manifest.json` と `audio/voicevox/clips/*.wav` を同じコミットで登録する。
- AIへの有料音声リクエストは追加しない。既存の収録済み音声以外の台詞は、現時点では端末の音声エンジンで読み上げる。
