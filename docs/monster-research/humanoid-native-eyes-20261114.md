# 人間型モンスターの眼球重複・まつ毛品質修正（2026-11-14）

## 対象と不具合
今回の個別改修は **m034 血月ヴァンパイア（男女）** と **m044 深紫サキュバス** の目元だけ。過去ログで指摘された「目が飛び出る」「黒目が小さく／斜視に見える」「アイラインから目玉が浮く」「まつ毛が短い」を優先する。

元の人物素体 Superhero_Male/Female_FullBody.glb には目の描画があるのに、`src/monster-gothic-sculpt.js` が目の上へさらに実体球を重ねていた。具体的に `vampire-orbital-shadow-*`（黒い楕円球）、`vampire-blood-iris-*`（小さな赤い楕円球）、`succubus-narrow-crimson-iris-*`（小さい赤い楕円球）が重なる。さらにサキュバスには悪魔化粧によるアイラインとは別の太い眼化粧の重複があった。これらは**元の眼球と描画面の二重化**につながり、人物らしい瞳孔・白目を隠す。

## 実装
- m034/m044の偽の眼球・黒目・重複した眼化粧メッシュを撤去。元の GLB の白目・角膜・虹彩・瞳孔を隠さない。
- `createGothicUpperLashFanGeometry` を追加。左右の上まぶたに沿う小さな立体まつ毛6本（high）／3本（low）／8本（source）を**片眼1メッシュ**に集約。毛根は既存の頭ボーンへ接続し、攻撃・待機・回避・死亡の頭部回転にも追従する。既存の悪魔化粧と干渉する二重アイラインは削除。
- 男性吸血鬼・女性吸血鬼・サキュバスの装着テストを追加。左右の眼のメッシュ親、頂点/UV/法線の有限性、High/Lowの頂点・三角形数、偽の眼球メッシュが存在しないことを確認。
- 図鑑と召喚獣鑑賞ページの人型コスチュームアダプターのみキャッシュを更新する。召喚獣の姿・獣型のレンダラー本体は一切変更しない。

## 残る確認事項と制限
この変更は、過去の『飛び出た目』の一原因である**追加の人工眼球の描画**を除去する。元の GLB そのものの眼球サイズ、眼の高さ・左右の視線、まつ毛の肌密着度、化粧と実顔の干渉、正面・斜め・側面の実機写りについては未確認。品質の完成や「実写級」を保証しない。

次に目視するべきは、m044の正面/右45°/左45°・笑い/攻撃表情、m034男/女の眼窩と唇、さらに女性召喚の眼輪郭と首肩のすき間。GLB、主人公、町人、兵士の素体や共通骨格を変更せず、人間型専用の後付けモデルだけを修正する。獣型PR #345/#346 は保留のままである。追加有料APIなし。

## 同時改修：首・肩と衣装の隙間
`src/monster-regal-garments.js` の従来のカラーは上のリングほど幅が広く、首の周囲に浮いた襟を作っていた。今回、襟のリングを上に向かって細くし、胸に固定された一体型の肩ヨーク `createRegalShoulderYokeGeometry` を設けた。袖の付け根を覆い、胴体上部へ重なる6断面のUV/法線付きメッシュ。胸骨に付属するため、独立した丸い肩当てが空中に残る方式ではない。鎧あり/なし、high/lowの別形状を持つ。対象は同じ人間型アダプターを使う衣装13パターン。元の人物GLB、共通ボーン、獣型には一切変更なし。

回帰QAは全衣装でヨーク1個・胸骨親・袖と首への重なり・幅と高さ・上ほど細くなる襟・高低LOD・頂点の有限性・描画予算を確認する。**実機の全アクションで衣装交差がゼロになることは未証明**。衣装貫通・首の実形状・角度別の見え方はE2E画面と実Android目視で追加確認が必要。
