# 灰銀のレゾナンス｜紙芝居の固定ビジュアル

このフォルダーは本作の20章・200ステージ・各7コマの漫画に使う高精細の原画マスターを格納します。

- `title.webp`：承認されたタイトル画。フルカラー1280×720。
- `cast/{id}.webp`：20人を**同じ人物ID**で全章にわたり再利用するポートレート（480×700）。
- `chapters/{01..20}.webp`：章固有の背景マスター（960×540）。
- `src/story-cinematic-assets.js`：上記画像を話者ID・章番号・コマ順に応じて合成するレンダラー。
- `src/story-manga-art.js`：Canvas/WebP非対応や画像読み込み失敗時のSVG代替絵。

## 人物の整合性

キャラクター名、役職、所属、秘密、成長は `src/story-cinematic.js` が正本です。
服装・顔のマスターアートが更新されても、同じIDの `cast/*.webp` を差し替えるだけで、
全章・全ステージに反映できます。人物画像と3D戦闘モデルは独立しており、
制作中の高品質3Dモデルに干渉しません。

## 現時点の制作範囲

この初期セットは**本チャット向けに新規生成した画像**から主要人物と背景を抽出した
シネマティック暫定版です。一部の人物は同じ集合原画から切り出したため、
見た目の差や職業・年齢の再現性はまだ不十分な場合があります。
章背景にも集合イラストの一部を再編集しており、各章に専用描き下ろしの
背景・ポーズ・全ての7コマの固有カメラ絵が完成したものではありません。

正式版では人物の個別原画と章ごとのシーン専用背景を個別に置き換えることで、
同じ読み上げ／漫画進行／セーブの仕組みを保ったまま品質向上できます。

## ライセンス／データ

画像は本会話用に生成されたオリジナルのAI絵を編集したものです。
既存ゲームキャラクターの画像や漫画・写真素材を転載したものではありません。
