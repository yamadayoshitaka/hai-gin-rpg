# 犬・狼系モデルの品質基準（v4.4.86）

## 原則
- 元のプロシージャルモデルを標準にする。Quaternius CC0の低ポリゴンGLBは比較・モーションの参考用で、品質が劣る場合は戦闘へ自動採用しない。
- 最初の改善対象は、召喚獣「灰狼」とモンスター5体「灰牙の狼王／紅蓮の獄狼／氷霜フェンリル／雷迅の魔狼／翠森の古狼」。
- 元の毛皮アルベド・ノーマルテクスチャは維持する。今回の追加は**毛の輪郭を立体化するメッシュ**であり、毛皮の実写スキャンを新規取得したものではない。

## 顔の造形
- 成体の細長い頭骨。鼻筋から鼻端を滑らかにつなぎ、濡れた鼻と左右の鼻孔を独立した造形にする。
- 目は大きな球ではなく、重い上まぶたの下に小さく埋め込む。耳は尖った形と暗い内側を分離する。
- 頬と首周りには毛の層を複数設けるが、眼球や顎の開閉を塞がないこと。

## 毛の描画・性能
- 胴、首・頬、尾の毛流れを個別に定義。毛先は後方へ流れ、表面法線から少し浮き、輪郭が光でわかること。
- 近景（high/source）は一枚の集約メッシュに多数の細いテーパードリボンをまとめる。数百枚の独立したオブジェクトを作らない。
- 遠景（low）はリボンを省略し、従来の毛皮PBRテクスチャを共有する。
- 召喚獣のhighモデルは125,000頂点未満を維持。GPUインスタンス化を継続。
- 5体の狼モンスターはそれぞれ毛束合計700本以上、毛束の描画メッシュ12以下、低LODの毛束ゼロ。
- 50体切り替え後の材質解放漏れゼロ。

## 回帰テスト
`npm run test:canine-quality`

加えて`npm run test:battle`およびPlaywrightのAndroid画面テストで、召喚獣一覧の「灰狼→顔・継ぎ目を拡大」操作を確認する。

## 未完了・過大評価しないこと
- 高品質な犬や狼の筋肉・鼻・皮膚・毛の外部スキャンを導入したわけではない。
- 毛の風・雨・重力による独立物理モーション、眉や唇のブレンドシェイプ、前足の爪の独立IKは別作業。
- この改善によりライトニング級/CGTrader高品質スカルプトに達したとは断定できない。
