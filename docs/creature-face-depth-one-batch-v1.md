# 灰銀のレゾナンス｜顔の平坦化解消・1バッチ回帰仕様 v1.0
作成日：2026-11-13　実装ブランチ：feature/batch-creature-face-volume-regression-20261113

## 一括実行
```bash
npm run batch:creature-face-quality
```
これが唯一の手動実行起点。召喚獣形状、モンスターの骨格・表情、顔3D頂点/3/4ビュー投影、近/遠LOD、戦闘で再利用する描画部品を**同じ変更単位**で回帰検証する。PR/CIでは既存のbattle E2Eを追加実行する。

## 共通7パラメータの正本
`src/creature-face-volume.js`
| パラメータ | 実3Dの変形対象 | 避ける不具合 |
| --- | --- | --- |
| craniumDepth | 頭蓋の後・側面の体積 | 平面頭蓋・薄い側頭部 |
| browDepth | 眉弓～額の隆起 | 眼窩周囲が一枚板 |
| orbitalDepth | 虹彩後方の眼窩の窪み | ボタン目・斜視・目の埋没 |
| cheekDepth | 目の下の頬骨・咬筋 | 斜め45°からの薄い顔 |
| snoutDepth | 鼻梁～吻の前後差 | 鼻先が平面または棒状 |
| jawDepth | 下顎の輪郭、顎角・頤 | 浮遊した歯のトレー |
| occipitalDepth | 後頭骨の後方膨らみ | 後頭部の薄さ |

すべて実際のposition頂点を変形する。装飾球体やテクスチャの偽陰影で合格扱いにしない。低/高LODで同一の連続した体積変化を維持し、巻き戻し可能な決定論的生成にする。種族ごとに値を個別設定（狼・軍馬・飛竜・古竜・天竜・竜王・森の精霊・天使、魔物各系統）。

## このバッチの適用範囲
- 戦闘用召喚獣：8種（狼、馬、飛竜、古竜、天竜、竜王、森の精霊、天使）。
- 魔物図鑑：骨格に適合する31種の頭部（狼5、猫科5、鳥4、爬虫類5、不死系5、魔族5、海蛇1、珊瑚の海神獣1）。m020の海蛇は爬虫類に含まれる。鴉天狗m015は既存の人型頭部を維持。
- ゴーレムは岩石・金属の硬質断面、昆虫/蜘蛛は外骨格、蛸・スライムは水生の固有形状を維持。ヒトの頬を無理に貼り付けない。人間主人公/仲間用の保護GLB・共有顔モジュールは無改変。

## 回帰合格ゲート
1. 45°断面: `sculptAxialFacePoint` と `sculptVerticalFacePoint` の頬張り、眼窩凹み、鼻先、後頭部の前後変位をゼロ形状と比較
2. 実メッシュ: 人型の顔ロフトの頂点数を増やさずに位置と法線が変化していること、31種でfaceVolumeApplied確認
3. 可動域: 竜王の閉口時4断面の顎接触テスト、その他の既存jaw pivot/瞬き/口追従を維持
4. 軽量: 狼125k、馬155k、飛竜175k、古竜175k、天竜205k、竜王225k頂点未満、遠景モデルは高画質より大幅に軽い
5. 異常検知: NaN法線/頂点、共有パーツの欠落、SkinnedMesh/マテリアル解放漏れ無し
6. 既存の50種骨格・猫科眼・不死系包帯・翼根元・召喚獣/乗騎の回帰テスト成功

## 目視品質ゲート（CIだけでは保証できない）
各代表モデルの **正面・真横・斜め45°・見下ろし** を同じズーム/照明/閉口状態で比較し、頬・眼球・鼻梁・顎・後頭部の陰影と形状の連続性を確認する。竜王の口開閉を併記。Android実機FPS/発熱も評価。自動テストの成功だけで「実写級になった」と表現しない。

## 管理上の制約

- 形状数値、顔の設定、QA、画面のキャッシュバージョンがすべて揃って初めて反映完了とする。
