# リギング済み装備への移行

## 方針
現在の `motion-external-test.html` の装備自動切断・自動フィットは暫定プレビューとして扱い、完成判定には使用しない。装備は人物と同じアーマチュアにスキニングしたGLBへ段階的に置き換える。

## 制作手順
1. Blenderでゲーム使用中の7頭身キャラクターGLBを読み込む。
2. 対象の鎧GLBを読み込み、同じ姿勢・スケール・向きで身体に合わせる。胸当て・肩・腰・手・脚・足の各部品を目視確認する。
3. 装備メッシュと人物の骨格を使って `tools/rig_outfit_blender.py` で自動ウェイトを生成する。自動ウェイト失敗時は処理を止める。
4. Blender上で待機・歩行・ダッシュ・斬撃・ジャンプ・しゃがみの各姿勢を再生し、めり込みや追従の破綻を確認する。必要に応じウェイトを修正する。
5. 検証済みのGLBだけをゲームの装備マニフェストに登録する。未検証の元GLBは素材候補として保持する。

## CLI
```sh
blender -b --python tools/rig_outfit_blender.py -- body.glb aligned_armor.glb rigged_armor.glb
```

**注意:** スクリプトは自動で人体へ位置合わせしない。入力装備は事前にBlenderで位置合わせしておく必要がある。出力GLBが存在するだけでは品質合格ではない。実機表示・アニメーション・貫通検査の合格が必要。

## 完了条件
装備が胸・腰・四肢に正しく追従し、複数姿勢で浮き・貫通・過大変形がないこと。GitHub Actionsのビルド成功は装着品質の証明ではない。
