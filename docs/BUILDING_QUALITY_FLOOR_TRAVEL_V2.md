# 建造物品質・階層移動 v2（2026-11-05）

## 目的

- 既存の建物・城の外観を構造化BOMとして高密度化する。
- オブジェクト一覧と実際の軍団戦マップで同じ3Dオブジェクトを使用する。
- 選択した兵士が、地上の入口→螺旋階段→2階へ**歩いて**移動できるようにする。
- 城では2階→3階、逆方向も同じ階段の逆経路で移動できる。

## 建築の追加

- 民家・店舗・教会：外壁の階層見切り、奥行きのある窓枠・雨戸、窓下花台、屋根コーベル。
- 城：1〜3階を視覚的に区切る組積造の帯、狭間窓、まぐさ、石の窓台。
- 追加カタログ：`stone_archway_001`、`stone_steps_001`、`wooden_watchtower_001`、`stone_column_001`、`wall_torch_001`、`haystack_001`、`inn_sign_001`。
- 新しい装飾はオブジェクト一覧に自動表示。軍団戦の町への配置は、道路・川・建物・既存の小物との重複検証を通して実行する。
- 追加小物の細部メッシュは材質単位で結合し、描画コールの増加を抑える。

## 軍団戦での操作

1. `tactics-wireframe.html` の通常戦闘（50対50）を開く。
2. 味方兵士をタップして選択する。
3. 右下「⬆ 2階へ」を押す。
4. 兵士が入室可能な近隣建物の南側入口へ移動し、螺旋階段の踏み板に沿って上がる。
5. 2階に到着すると待機し、「⬇ 1階へ」で同じ階段を下りる。城は「⬆ 3階へ」にも対応。

入口の鍵は `evaluateBuildingEntry` で判定する。一般兵士の所持鍵はLv.1、公開施設は従来どおり開放、ストーリー戦では城の許可を適用する。室内の階段には追加の鍵判定はない。

## ナビゲーション

- `src/building-floor-navigation.js` が建物BOMから階段の座標、高さと上下双方向のウェイポイントを生成する。
- 入口までは既存のマス移動と壁回避A*を使う。階段上ではモデルの水平座標と足元の高さを連続補間する。
- 2階床は兵士がそこにいる間だけ表示。城の3階床は2階到達時には非表示にして視界を遮らない。
- 地上の重複禁止マスとは別扱いで階段を登り、着地時に空きマスへ復帰する。

## 今回の範囲と制約

- 兵士個人への階層移動命令を通常戦闘に実装した。1000対1000の共有GPU・グリッドシミュレーションへはまだ階層AIを追加していない。
- 上階到着後は待機し、階下への帰還は手動。戦術AIが各階で敵を追跡して戦闘する機能は後続。
- Android端末での3D描画／実操作確認は別途必要。静的テストと回帰テストは追加済み。
