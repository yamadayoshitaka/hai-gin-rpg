# 灰銀戦記：20章イラスト制作フォローアップ／絵柄・人物・時系列引継ぎ v1.0

- 作成日：2026-11-11
- 目的：**現在別作業で進められている絵制作と、三国戦争・20章分岐シナリオの整合性を取るための制作指示**。
- 元設計：[`story-branch-flow-v1.md`](./story-branch-flow-v1.md)。
- ステータス：**資料・発注仕様のみ**。画像生成、画像の上書き、3Dモデル更新、音声変更、ゲームのデプロイは本コミットで実施しない。
- 既存コードの人物ID：`src/story-cinematic.js`。漫画のシーンID：`src/story-stage-manga.js`。

## 1. 最優先：画の狙い

- タイトル・城・町・戦場を含む**高品質な日本発ファンタジーRPGの物語画**。既存の簡易SVG、紙芝居感、同じ立ち絵を貼っただけの場面の量産を最終品質としない。
- **キャラの外見が20章を通して同じ**。顔の骨格、目・眉・口、髪型、髪色、体格、年齢、主要衣装・武具・紋章を「キャラマスター」に固定する。
- 戦争の話をしているからといって、すべてを威圧的な戦場背景にしない。日常→異変→決断→戦争→喪失→和解→最終決断の感情曲線を描く。
- 表情と動作は台詞の意味に一致。主人公が何も知らない第1章で、先王の死や記録院の正体を知っているような絵・台詞にしない。
- アニメ顔、写実、塗りの混在を避ける。**全員オリジナルのデザイン**とし、他作品の既存キャラをそのまま複製しない。
- 画像中の文字は原則描かない。日本語のナレーション・名前・字幕はゲームUI層で描画する。誤字や再レンダリングを減らす。
- 主人公の頭身・顔は別作業の最終3Dモデル確定を待つ。暫定画ではシルエット、背面、手元や視線で主人公の存在を表現し、**未確定の顔を固定しない**。
- 高精細の原画をマスターとして保存し、端末向け解像度・形式・軽量化は別工程で行う。

### 世界の意匠
- 灰銀：冷たい銀・青灰・王城石材。礼節、重層的な官僚制。
- 紅炎：赤銅・深紅・鉄の城壁。帝国の強さと住民の暮らしの両面。
- 翠嵐：緑・水・樹木・自然を組み込んだ王都。美しさの裏に魔力依存の不安。
- 記録院：古い帳簿、封蝋、記録装置、星鐘の部品。単純な暗黒集団ではなく「制度の怖さ」。
- 鐘守：記憶石、古い鐘の模様、千年前の技術。神秘的だが宗教一色にはしない。

紋章、装甲、衣装、顔は各国で意味付けを統一。**敵国の人物の顔を色替えだけで流用しない**。

## 5. 第13章の分岐絵と共通絵の分離

- `route=silver`：灰銀の王城・リュシア・ガラン。王国内の腐敗を正す決意。
- `route=crimson`：紅炎の要塞・ライゼン・セリカ。強硬派に背く共同作戦。
- `route=verdant`：翠嵐の水源と森・アルテア・ノエル。森を守りつつ記録を開く。
- `route=independent`：国境の中立地・三国の使節。誰の王旗にも属さない調停軍師。
- 第14〜15章：上記ルートで背景・旗・援軍・話者は差分を作る。**人物の顔や過去を変更しない**。
- 第16章以降：三国共同戦線へ合流し、同じ人物が過去ルートから自然に登場する。以前の救出・敵対・負傷等の結果に応じた差分絵を許可。
- 第20章：解放、封印、忘却のエンディング絵は**3枚別の固有構図**。主人公の記憶が消える場合も、過去絵の主人公を別人に差し替えない。

- `assets/story/characters/garan/master.webp`

**章・ステージ場面：**
- `assets/story/chapters/ch01/key-visual.webp`
- `assets/story/panels/c01-s01-m01.webp` ～ `c01-s01-m07.webp`
- `assets/story/panels/c13-s01-m01__crimson.webp` など、ルート固有の場合は末尾にルート名。
- `assets/story/endings/release.webp`、`seal.webp`、`inherit.webp`。

上記は**推奨納品パス**であり、既にこのパスの全ファイルが存在するわけではない。現在の `src/story-manga-art.js` はSVGの描画ロジックを使用するため、原画のファイルをGitHubへ置いただけではゲーム表示が自動で切り替わらない。画像パスを参照するアダプタの実装・QAが別途必要。

### シーンに付与するメタデータ（設計）
- `stageId`：`c01-s01` の形式。保存用に安定。
- `panelId`：`c01-s01-m1` の形式（現行の漫画データと一致）。
- `characterIds`：人物ID配列。姓名ではなくIDで参照。
- `chapter`、`chapterTitle`、`location`、`scene`、`mood`、`timeOfDay`。
- `route`：共通なら `common`、第13章以降のルート差分なら `silver/crimson/verdant/independent`。
- `masterVersion`：同一人物の顔・衣装マスターに紐づく版。
- `scriptRevision`：該当台詞・出来事の版。絵だけが旧設定にならないようにする。

## 8. 品質チェックリスト

- [ ] 主要人物20名のIDと外見マスターが1対1で対応。
- [ ] リュシア／ガラン／イリスの第1章初登場が自然で、紹介前の事件説明が過剰でない。
- [ ] 同一人物の顔・髪・装備・身長感がコマや章をまたいでも大幅に変化しない。
- [ ] 灰銀／紅炎／翠嵐／記録院の建築・軍装・旗が混同されない。
- [ ] 章別キーアート20枚に固有の事件・背景が描かれている。
- [ ] 画が台詞の「場所・人物・行動・感情」と一致し、別場面の流用に見えない。
- [ ] ルート分岐後に味方と敵の国旗が逆転していない。
- [ ] `c01-s01` の7コマとタイトルの6コマ表示は二重初対面にならない。
- [ ] 第20章の3結末はそれぞれ別の画面演出を持つ。
- [ ] 未確定の主人公3Dモデルと矛盾する顔の設定を固定していない。
- [ ] Android実機の縦横比で主要な顔・表情が字幕やUIに隠れない。
- [ ] 変更後の回帰テストで町3Dと50対50／1000対1000戦闘を劣化させない。

**この資料は画像制作の引継ぎを目的とする。別チャット・別作業の画像生成が自動でこのGitHub資料を読む仕組みではないため、必要に応じて当該作業にこのURLを提示して参照すること。**
