# 第1〜5章：150コマ・1枚絵 → 切り出し → ゲーム登録 → コミット

## 制作工程（単一コマンド）

`scripts/run-story-chapter-pipeline.py` が章全体を一括処理します。

1. 正式な章あらすじ・全10ステージの目的・コマ用セリフを読む。
2. 各ステージ15場面、**1章150コマ**を事前に対応づける（最初の町は前10+後5、残り9ステージは前8+勝利確認後7）。
3. 男女ごとに**別のオリジナル高精細原画**を用意する。分岐・敗北・主人公戦死は別の原画（勝利原画の流用禁止）。
4. 必要に応じて20枚の実原画を、1536×行数×432のページで制作する。統合して**7680×6480ピクセル、10列×15行の大判150コママスター**にする。
5. マスターから本物の150コマを **768×432の個別WebP** として切り出し、台本・ふりがな・VOICEVOXに対応するIDを紐づける。
6. ステージの前後各1ページ、**20個のゲーム表示用WebP**を組み立てる。
7. 画像のサイズ・重複・破損・担当章・場面の順序を検査し、原画と台帳を登録する。
8. `--commit` を指定すると登録したファイルだけをGitにコミットする。無い絵は**決して生成済み扱いで登録しない**。

### 実画像がある場合の全章・男女一括コマンド

```bash
python scripts/run-story-chapter-pipeline.py --all \
  --atlas-dir assets/story/atlases --commit
```

この入力形式では、例えば `assets/story/atlases/c01-male-mainline-150.webp` と `c01-female-mainline-150.webp` のように、計10個の**実在する**150コマ原画が必要。1個でも無ければ開始前に止まります。

20枚ずつの高精細原画を先に持っている場合：

```bash
python scripts/run-story-chapter-pipeline.py --all \
  --source-dir assets/story/chapter-drafts --commit
```

各 `assets/story/chapter-drafts/cXX-male/` と `cXX-female/` に、制作計画に指定された20個の実原画を格納します。コマ画像が一つでも不足すれば偽画像を補填せず停止します。

### 画像作成前に全コマ割り・セリフの対応を出力する

```bash
node scripts/compile-story-chapter-atlas.mjs --all
node qa/story-150-panel-atlas.test.mjs
```

`qa-reports/story-chapters/c01-male-mainline-150.json` ～ `c05-female-mainline-150.json` に、5章×2性別×150＝**1500コマ**について「場面説明、位置、台本、声優、音声キャッシュキー、画像ファイル、ページファイル」の対応を保存します。

## 原画の絶対条件

- **画面に文字・数字・吹き出し・ふりがなを一切描かない。** 画像の外にセリフ／ruby／VOICEVOX音声を表示・再生する。
- 1枚の低解像度1024px画像を無理やり150分割すると、1コマの画質が不足するため不可。**7680×6480の実画素を確保**し、遠景・顔・物証を各コマで描き分ける。
- 登場人物の髪・顔・装備を原画で照合。主人公男性と女性、リュシア、ガラン、イリスは別人物。
- 勝利・敗北・ゲームオーバー・方針選択の原画を混ぜない。今回の150コマ台帳は**町と勝利メインルートの150コマ**であり、その他の分岐原画は別制作。
- 自動QAは破損・サイズ・完全一致の重複を確認します。文字の有無や顔の完全一致を自動で保証しないため、**絵の目視レビュー**が必要。自動生成画像を人間の承認済みと偽装しない。
