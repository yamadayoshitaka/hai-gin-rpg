# v4 動作品質改善
走行/歩行: 支持脚と遊脚の足首目標を連続的に補間し、股関節・膝を二節IKで解く。つま先角は実際の骨格の足首→つま先方向から求める。重心上下動を連続化する。床衝突は未実装。
パンチ: 拳を前腕の方向へ整列、掌を下方へ向ける回内を前腕・手首に配分する。個別骨格に依存した見た目の確認が必要。
動作スタイル: 自然/穏やか/元気/力強い/疲労。速度、歩幅、足上げ、腕の動作幅を調整。表情は自動または手動。
読み上げ: 日本語読み仮名解析は別スレッド、母音/閉口を順次再生。表情と口パクを混合する。標準顔は顎のみ。端末音声合成、音素時刻は近似。
検証: 足首目標の有限性、周期、支持区間、表情選択、実ブラウザ動作。視覚的な足滑り・拳の自然さ・口パク同期は実機評価を要する。
