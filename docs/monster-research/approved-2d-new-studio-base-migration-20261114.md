# 承認済み2D設定画と新しい人モデルへの移行契約（2026-11-14）

## 決定
ユーザーは、女性人型の「森の精霊弓士」「竜王」「光翼の守護天使」の2D設定画と、「人形モンスター」4種のコンセプトシートを**見た目・衣装・顔の品質基準として採用**した。現在の旧人間素体を仕上げるのでなく、**別ラインで制作中の人モデル**へ将来切り替える。イラストの自動出力は、実用可能な3Dモデルや衣装/スケルトンの完成を意味しない。

## 現行実装の事実
- 現在 `src/monster-character-cosplay.js` は、男女の旧 `Superhero_Male/Female_FullBody` を `profile.modelId` で呼び出す。 `src/female-summon-forms.js` の3体も旧女性型。
- 新しい人モデルは `face-body-studio.html` / `male-body-studio.html`、`src/studio-unified-neck-v59.js`、`src/heroine-battle-costume-bridge.js` で改善中。v59は顔と首の接合品質が上がっているが、モンスター/召喚獣で使用する独立した本番スキン付きGLB/契約としてまだ配備されていない。
- 顔/髪/眼球/表情/年齢・体型の改善は人モデル制作側を正本として取り込み、モンスターごとに別々に人の顔を作り直さない。
- 既存GLBや新しい人モデルの制作コードを、モンスター専用修正から直接書き換えない。

## 受け渡し
設定画原本4枚は、この会話で生成・ユーザー採用済みの画像として、会話のダウンロードZIP `hai-gin-approved-2d-human-base-migration-v1.zip` に保管。**画像バイナリはこのPRに含まれず、下記manifestでは repositoryPath=null**。画像をリポジトリへ正式登録する際はSHA-256で照合すること。画像が未登録なのに登録済みと主張しない。

### 女性召喚獣（優先順）
1. `forest_archer`: 金/銀白のロングヘア、頭皮がはみ出さないウィッグ、上品な目・顔、紺と金の森装束、弓・矢筒。衣装は手足と骨格の位置へ密着。
2. `dragon_lord`: 銀紫ロングヘアの竜女王、骨の内側から生える角、繊細な紫目、女性の顔を残す頬の鱗、黒/赤/金の王族衣装。**今回承認した2Dは従来の「坊主頭/被せた半球」3D表現より新しく、見た目の正本**。ただし現在のゲーム戦闘である竜王の能力・翼・飛行などは維持。
3. `seraph_guardian`: 銀白ロングヘア、白/金/紺の聖装、高品質な元の重層フェザー翼、飛行/羽ばたき。2Dとの顔/装飾の一致を検証する。
4. 人形系: 「磁器の人形姫」「傀儡の暗殺人形」「ぬいぐるみの守護人形」「時計仕掛けの魔導人形」の**4案はアート原案**。現行50種のIDには未対応のため、勝手にm031〜m045等に割り当てない。

### 人モデル制作側から受け取るもの
- 男女のゲーム向けスキン付き完成素体（顔・首・胴体が接続、眼球・口・表情/瞬きの本来のメッシュ）、モデル/リグバージョンおよび実体のGLB参照先。
- 正確なBodyShape ID（`slim` と `ultra_slim` を分離、旧痩せ型を超痩せ型へ再分類）、年齢帯・男女ごとの有効なプリセット。
- アニメーション互換：`idle/walk/run/attack/hit/dead` と召喚飛行、左右上腕・胸・手・頭・骨盤・脚のボーン/アタッチメント。
- 新モデルが実際に動くことを確認するE2E、首/肩・衣装/角/羽の位置ズレとスマホFPS。

### 移行の順番
1. **新モデル側を壊さず**新人体のアセット/骨格契約と顔プリセットを確定する。
2. モンスター専用**人体プロバイダー・アダプター**を用意し、先に女性召喚3体で旧体→新体を差し替え、残る16種は段階的に。
3. 既存の衣装/翼/角/武器アタッチメントを**新しい実ボーン位置で再採寸**し、元人体と被る頭皮/肌は新素体上の対象領域だけを減算（顔/耳/首を切らない）。
4. 承認2Dから **正面・左右45度・後ろ・真上の画像**を比較し、顔立ち、瞳、前髪、身体、衣装のずれ、貫通、装飾、羽、飛行の一致を確認する。
5. 全体CI/戦闘E2E/スマホ検証後にデプロイする。新モデルが未完成の間は既存のゲームプレイを停止させない。

## 禁止
人物制作中の共通GLB、主人公/NPC/兵士のメッシュ、グローバルモーションや骨格をモンスター側から変更しない。完成していない素体をmainへ強制切替しない。既存の天使の高品質羽・飛行を劣化させない。獣型PR #345/#346 は別件として保留。有料の画像/3D生成APIを追加しない。
