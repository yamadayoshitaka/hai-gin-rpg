# 灰銀のレゾナンス — 顔モデルv15 修正実装仕様（2026-11-12）

## 正本と非対象

正本は Library の `female-saved-preset-contact-makeup-v8.glb` から取得した顔設定。顎先5・鼻穴隠し2・鼻筋2.5・目サイズ1、その他の保存値を維持し、全スライダーの中央50%に配置する。男性は同じ顔原型から化粧を除外。既存の町、戦闘、胴体、頭部原本GLBは変更しない。

## 関数／ファイル単位

### `src/face-feature-meshes.js` — 眼窩追従

- `createAnatomicalFaceParts()` が元頭部の実表面にレイを飛ばし、目頭・目尻・上まぶた中央・下まぶた中央の4点を得る。
- 眼球の深さを4点の平均から求め、横顔で角膜が顔面に隠れない最低クリアランスと、正面で浮きすぎない上限を両立させる。
- まぶた内縁を眼球の楕円体の表面方程式へ投影する。眼球、虹彩、瞳孔、上・下まぶた、アイライン、目元の色は同一ジョイント座標へ。
- 受入条件：正面、45度、横からの眼球視認性。目角度±20°で眉が埋まらない・繋がらない。目サイズ変更でもパーツが離れない。

### `src/face-feature-meshes.js` — 口紅、アイシャドウ、チーク

- `createAnatomicalFaceParts()` は顔の3D表面の縦曲率から口裂を検出する。上唇／下唇の自然な立体ボリュームは残すが、口紅を別の板へ塗らない。
- `updateRealFacePigment(face,controls,mode)` は元の顔メッシュの頂点色で唇領域と頬領域を着色する。口紅の幅・位置・高さ変更でも板を移動させず、顔から浮かない。口周辺以外・顎への色にじみはマスクで制限。
- 上まぶたに沿う RGBA グラデーションアイシャドウを左右各1枚生成。まぶたの親子階層を使い、目角度の変化に追従。チーク強度を上げ、頬上部の面にソフトフェード。
- 受入条件：口紅の色は顔メッシュに存在、独立した口紅板なし。眉・まつ毛・上下まぶた・アイシャドウが連動。男性に化粧を出さない。

### `src/face-scalp-wig.js` — grow → relax → collide → trim

- `actualScalpCandidates()` で頭頂・前髪・左右側頭・左右後頭・襟足の9ゾーンを分配する。
- `scalpShell()` で髪色の連続した頭皮カバーを作り、10万本の必要性をなくす。標準の1,440束（調整可）は目で見える髪型用。
- `createHeadEnvelope()` が元の頭部メッシュから高さ×角度の実測外形を計算する。毛束を毛根法線から伸ばし、連続する各節点を頭の半径より外側に沿わせる。
- `hairCutY()` で前髪、側頭、後頭、襟足別の長さ制限を最後に適用。前髪は目元を隠さないよう眉上でカット。
- `resolveCollision()` は顔・頭・肩・胸の当たり判定で貫通を防ぐ。
- 受入条件：正面・側面・背面・頭頂の頭皮露出が目立たない、毛束の根が実頭皮頂点に存在、カット後の先端が設定線以下に降りない、頭や肩への貫通抑制。

### `face-mesh-studio.html` — スライダー軽量化

- 口紅スライダーは `input` 時に `updateRealFacePigment()` のみ実行し、軽い頂点着色で即時反映。顔GLBや髪の再生成なし。
- 鼻・顎・目などの実形状変更は指を離した `change` でのみ顔メッシュを確定。
- 顔のみ変更したとき、髪は元のオブジェクトを新しい頭部へ付け替え、髪メッシュや衝突場をゼロから再計算しない。
- `createScalpAnchoredWig()` では頭部の外形をWeakMapキャッシュし、1,440束のうちガイド約300束を20Hz物理計算、陰影再計算は3フレームに1回へ。
- 受入条件：ズーム保持、髪の有無・口紅操作でズーム戻りなし、口紅の入力時は髪・顔の再生成回数が0、顔形状変更時は髪再生成回数が0、男女GLBエクスポート成功。

## 検証

`qa/independent-face-masters.test.mjs` で頂点・リポート・髪根・着色・ジョイント・保存値を検査。`qa/independent-face-masters-browser.cjs` でChrome実描画、正面/斜め/側面/背面スクリーンショット、スライダー/ズーム/書き出しを検証。顔専用CIが通るまで本番マージしない。

## 制限

本方式は顔確認画面用のプロシージャル頭皮カバーと簡易衝突モデル。全身スキニング、実際の髪一本単位の物理、セグメンテーション由来の唇頂点タグを保証するものではない。特に見た目の最終判定はユーザー実機画像との比較が必要。
