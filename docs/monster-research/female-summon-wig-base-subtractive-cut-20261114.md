# 女性召喚3体の「ズラのベースより下に頭が出る」不具合への減算修正

## ユーザー画像・原因
2026年11月14日 17:47 の実機スクリーンショットでは、森の精霊弓士の髪の下から灰色の後頭部が球体のように突出して見える。天使も同種のウィッグ式髪・原頭部との二重描画、龍王は本頭部と鱗装甲の重なりが問題。過去の「毛束168本追加」「頭骨採寸」「写真素材変更」は**描画される頭部の三角形を一切取り除いておらず**、原因を除去できなかった。

## 実装
`src/female-summon-scalp-cut.js` は、**表示中のSkinnedMeshだけ**元Geometryをcloneし、頭頂部分を覆うウィッグのベース領域（または龍王の薄い鱗板領域）の中にある、本物の頭皮三角形を削除する。元GLBのデータ・肌・骨・アニメーション・テクスチャはそのまま。

1. Headボーンへのウェイト0.73以上、元骨格のモデル上向きアンカーでスキニングした頂点のみ処理する。
2. ウィッグの頭頂球面の極角・前髪の生え際・顔と耳の境界を基準にする。**三頂点がすべて**頭頂の隠れる領域にある三角形だけを削除。境界や耳・顔・首は残す。
3. GLBのマルチマテリアルを壊さないよう、元のgeometry.groupsに対応して切断後のindex/groupsを組み直す。UV、法線、モーフターゲット、skinning attributes、元のsource geometryは維持。
4. 髪（森の精霊弓士・光翼の守護天使）では、頭皮計測と毛束生成後に頭皮だけをカット。龍王では**実頭皮三角形から作った薄い鱗装甲が有効な場合のみ**下の頭皮をカットする。鱗装甲が生成できない個体で頭をくり抜かない。
5. ステージ再ロード・モデル切り替え・dispose時には、複製Geometryを破棄し、元geometry参照を正確に復元。主人公・町人・兵士・獣型のGLBには変更なし。
6. 真上・斜め後ろ・正面の3方向で切断の境界と顔・耳・首が保たれているか実機比較する。ブラウザQAでは元のGLB上で切断三角形数が正となることを必須にした。

## テストと状態
`qa/female-summon-scalp-cut-regression.test.mjs` は実SkinnedMesh相当の合成顔・頭皮を使用し、カット前後の三角形保存と再ロードを確認する。過去の天使の元多層羽・浮遊、龍王の実頭蓋に沿う鱗、他モンスターの体型は変更しない。

**限界**：実装と合成3D回帰が通過しても、GLBの実体でHeadボーン比率や頭頂描画面が異なる場合、実機で一切見えないと保証できない。`sourceCraniumWigCut`および`sourceCraniumRemovedTriangles`をブラウザ診断へ出し、写真と合わせて検証する。追加課金APIなし。
