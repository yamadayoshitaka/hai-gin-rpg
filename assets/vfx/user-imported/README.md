# 2D effect sprites supplied by the game author

Imported into `gray-silver resonance` as transparent PNG billboards. The
runtime instantiates them only for visible action events (not each 1000-unit
crowd instance); 3D arrows and travel arcs are generated from geometry.

`FX.zip` includes an upstream note from Martin Jelinek allowing free project
use. Other uploaded archives contained no license document. Before selling the
game, verify the publication/commercial permissions for those archives.
