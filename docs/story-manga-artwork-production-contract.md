# 灰銀のレゾナンス — 漫画原画・一ステージ単位の制作契約（厳守）

適用: 第1章〜第20章、男性・女性版、イベント前・勝利・敗北・ゲームオーバー・町イベント後、全シーン。

## 絶対禁止 — 台本と原画の整合性

1. 原画の中に **数字（「01」「02」「04」等）、コマ番号、文字、セリフ、字幕、見出し、ふりがな、UI、透かし、装飾バナー、フレーム番号、ウェブサイトURL** を描かない。
2. 画像生成器へ **確認画面・漫画一覧・ダッシュボード・ポスター・完成報告・PR番号** を描かせない。ゲーム内の画面表示と漫画の「原画」は別物。
3. 10コマの一覧絵をそのまま1コマとして登録しない。単独の16:9原画を先に完成させ、必要な場合だけ後から2列の保管用シートを組み立てる。
4. 男性主人公の絵を女性版の主人公が必要な場面に流用しない（逆も同じ）。性別を変える場合は **主人公の見た目だけ** を差し替え、他の人物の身元・舞台・事件・構図を維持する。主人公が登場しない景観・物証は同一の画を使ってもよいが、登録先は男女別にする。
5. シナリオと一致しない場面、別の勝敗・主人公戦死・別のステージの絵を代わりに表示しない。
6. 全シーンを確認する前に「完成」「デプロイ済み」「品質承認済み」と報告しない。
7. 生成画像に含まれるデプロイ完了やURL等の文字を、実際の実行結果として扱わない。

## 1ステージ完了の条件

1. `comicForStage(stage, phase, {protagonistGender})` の **全コマのID、担当人物、場面、音声の読み** を先に確定する。
2. 男性版の各場面の独立原画を作成。確認後、同じ構図で主人公を女性に置換し、女性版の独立原画を作成する。性別を変えてはいけない固定キャラクター（リュシア、ガラン、イリス等）は維持。
3. 原画ごとに、文字・数字・枠・UI・画面内の透かし・性別混入を目視で確認。該当するものは **却下して再作成**。
4. `panels/{shotId}-{gender}.webp` と、同じ画像から組み立てた保管用シートを別々に保存する。原画は最低768x432 (16:9)、サイト表示では登録済み単独原画を優先。
5. 男性・女性、すべてのイベント分岐についてファイル存在・WebP正常性・実IDとの一致・前後/勝敗の独立性を検証。
6. 実ゲーム（タイトル/町/戦闘前/戦闘後）でセリフごとに1枚だけ表示されることを検証し、mainへコミット・マージ後、GitHub Pagesの成功を確認する。
7. 人間が未承認の場合は「初稿」と明記し、品質承認を作業完了と混同しない。

## 生成プロンプトの冒頭に必ず付与する制約

> これはゲーム内でセリフと別表示する **16:9の単独の一枚絵** です。絵の中に文字、数字、番号、コマ割り、吹き出し、字幕、ロゴ、UI、枠、URL、ウォーターマークを一切描かないこと。シナリオで指定された出来事だけを描くこと。人物ID・役職・衣装・髪色・顔つきの一貫性を維持すること。男性版を女性版にするときは主人公だけを女性軍師へ置換し、他の人物と場面構成は維持すること。完成報告やゲーム画面を描かないこと。

この制約は生成器の遵守を保証するものではない。画像登録前の検品で必ず再確認すること。
