# 召喚獣・既存モデル混合デザイン v4.5.20

## 採用した原則

- **置き換えではなく、既存モデル同士の部位・造形の合成。**
- 灰狼は召喚獣 `wolf` の四脚歩行・口/尾アニメーション・写真毛皮/LODを主モデルとし、既存図鑑 `m001 灰牙の狼王` の胴体/頭部比率と毛色を **0.42** の重みで補間。さらにその造形に由来する肩まわり・頬の立体的な輪郭を追加する。
- 外部レジストリには検証済みの専用 `wolf` GLBが存在しない。外部GLBとの異なるトポロジーの頂点1対1混合は行わない。図鑑の m005、m006、共有主人公GLBにも変更を加えない。
- 飛竜は既存 `wyvern` を維持し、図鑑 `m017 鋼鱗バジリスク` から肩・頬部の立体的な鱗鎧を混合（重み0.22）。
- 古竜は既存 `dragon` を維持し、図鑑 `m018 毒棘ヒュドラ` から頸部の角状フィンを混合（重み0.26）。
- 天竜は既存 `elder_dragon` を維持し、図鑑 `m020 深海リヴァイアサン` から鰭状の頭部・頸部意匠を混合（重み0.18）。
- いずれも既存の翼・脚・尾・可動顎を再利用。高LODだけに少数の骨追従細部を追加し、モバイル頂点上限（飛竜/古竜175000、天竜205000）を自動検証。
- 竜王・森の精霊・天使も、前版の既存3Dソースメッシュ・アニメーションを利用した顔・髪・翼・衣装と色調整を継承する。新しい低品質GLBで置き換えない。

## 顔・肌・服

- **天使：白系の肌（#f4f4f2）、既存の高品質な多層羽を維持。** 金髪ロングのサイド/後髪は残し、目・眉が見える前髪に変更。
- **森の精霊：肌は自然な肌色（#e1b496）、服・葉・蔦はエメラルド～深緑。** 肌まで緑に染めない。天使の衣装・羽とは明確に区別する。
- 男性竜王の構造と元ドラゴン形態、階層化した衣装カバーは前版から維持。

## 大きさと既存ゲームルール

- `SUMMON_WORLD_SCALE=10`：召喚獣7種類のモデル描画を人間の10倍の相対寸法にする（既存種族ごとの基本差はそのまま）。軍馬は召喚獣ではないため1倍のまま。
- 元の人間キャラサイズ、魔法の計算式、移動ルート、戦闘の占有セル、攻撃射程と勝敗条件は今回変更しない。**画面上の巨大化と戦闘の物理衝突半径の全面改修は別件**。一気に半径を10倍化すると橋・狭路・屋内が壊れるため、まず描画と搭乗座席・飛行高度・ズーム/LODを同期する。
- スマホ鑑賞画面のカメラは10倍モデルを見られる距離へ自動調整し、顔・足先・毛皮のズームも同倍率へ補正。大きな個体でも描画が全て高LODにならないよう閾値は距離の平方根で調整。

## 戦闘前のUIと自動テスト
- 戦闘前の**①編成→②初期号令→③開戦**は変更しない。ユーザーの要望により、モデル品質完成後にUIの追加調整を検討する。
- `qa/opening-three-stage.cjs` から実際のボタンを選び、読み込み完了・音声なし起動などの正規ルートを確認する。テストの都合で状態を偽造して戦闘を開始しない。
- 適用対象：`qa/mass-battle-browser-visual.cjs` と `qa/ai-steel-battle-smoke.cjs`。

## 確認と残課題

- テストでモデル由来・補間数値、肌色、髪、サイズ、騎乗座標、性能上のLOD閾値を検証する。
- 個別のGLBを物理的にブーリアン結合する処理は実施していない。異なる骨格の結合にはリターゲット・メッシュ再構築が必要。
- 端末実描画で色温度、顔の前髪、足先の貫通、巨大化による遮蔽、占有セルの違和感を確認すること。
