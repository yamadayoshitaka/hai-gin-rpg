表示と手動指示について

「毎時有効」はスケジュールが有効という意味で、いま処理しているという意味ではありません。ChatGPT側は取得時点の記録を表示し、GitHub側は最新のActions履歴を取得します。

有効／無効：顔髪・衣装・オブジェクト・モンスター・召喚獣はGitHub Actionsのスイッチ連動。バッチの作業実行を切り替えるには各カードのボタンからGitHub Issueを開き、所有者が「Submit new issue」で確定します。ChatGPTの定期タスクそのもののON/OFF操作とは別です。旧一括人物・モンスターの定期タスクは停止維持します。

参考画像：ここに画像を選択・貼り付けて確認し、画像をコピーしてGitHub Issue本文へ貼り付けてください。画像はPagesから直接アップロードされません。

GitHub APIの403対策：ページ表示中は認証なしGitHub APIを自動連続呼出ししません。「状況を更新」を押した時だけ1回まとめて取得し、403・429時は再試行を抑制します。APIが403でもバッチ停止を意味するわけではありません。

実作業の工程別進捗：起動・ソース修正・QA・コミット・PR・マージ・公開を別々に表示します。「実作業未完了」は完了扱いにせず、次回引継ぎを表示します。工程台帳は最終保存時点、PRの最新コミットとマージ状態はGitHubから照会します。改修中の画面はPR版比較で開き、本編の公開SHAも別途照合します。

手動指示の送り方：各カードに修正内容を入力 →「GitHubでIssueを作成して起動」→ GitHubのIssue画面で「Submit new issue」を押す必要があります。GitHubへ移動しただけではバッチは起動しません。GitHubが403の場合は「ChatGPT用指示をコピー」から、このチャットに貼り付けてください。これは1回限りの依頼で、GitHub認証情報をこのサイトに入力する必要はありません。

旧人モデル一括・旧モンスター一括は停止。新しい4系統は10分間隔、オブジェクトは既存の6担当を毎時並列でQA実行します。漫画は既存のChatGPT定期タスクを維持します。現在のスケジュール有効/無効はこのサイトから直接取得できず、最新のChatGPT実行日時は記録時点の情報です。GitHub ActionsのQA成功だけで画像生成・3D修正・本編反映の完了とは判断しません。追加の有料API課金は行いません。
