# 灰銀のレゾナンス：スマートフォン向け原画の実画素サイズ（2026-11-13）
ユーザーはスマートフォン表示を前提に、既に切り出した幅787px・高さ350〜433pxの25枚を十分な画質と判断した。1536×864pxの従来下限は高画質（PC等）プロファイルとして維持するが、**スマホ専用配信用の最低実寸を768×320pxに追加する。**
スマホ版が適用されるのは「個別WebPをゲーム内で表示」する時だけで、巨大なシートの生成器最大画質を意味しない。元の縦横比は保ち、`object-fit:contain`で引き伸ばさない。
**寸法条件の合格は本番画像の完成を意味しない。** 現存25枚は、顔・衣装・マスター画像が本当に参照入力だったか、シナリオのどの正式場面に対応するか、男女・勝利・敗北・戦死、文字/UI混入が未検証。このP0検証を終えるまで正式IDとの対応付け・本番コミット・ゲーム公開をしない。
実物保管：`hai_gin_ch01_5_sheets_25_crops_DRAFT_20261113.zip`（会話の添付ファイル、GitHub上には未アップロード）。切り出しレポートでは25/25枚が最低寸法768×320を満たす。
