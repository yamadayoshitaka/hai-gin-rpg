# 召喚獣・軍馬 3D外観・攻撃・騎乗仕様 v4.4.69

状態: 実装済み（ソース・構造・音声波形・騎乗/命中回帰テスト）。実機での質感・鳴き声・FPS評価は継続。

## 共通契約

- 召喚獣・軍馬は兵士の衣装や人体骨格の一部にはしない。独立した world object として、ID・所属・HP・寿命・攻撃・移動・消滅を維持する。
- 召喚は N「灰狼」、R「飛竜」、UR「古竜」、一体生贄UR「天竜」、一体生贄UR「竜王」の5種類。召喚士1人につき同時1体まで、再召喚は入れ替え。馬は騎乗用 object。
- 召喚獣と召喚士は独立HPを保持し、互いに被ダメージの50%を1回だけ連動。召喚主が戦闘不能になると召喚獣も消える。
- 一歩＝1マスの既存ワールド座標を維持し、見た目のサイズだけのためにゲーム側座標を変更しない。
- 全種、顔・身体・四肢・尾・翼などを専用立体メッシュに統合。人間モデルや簡易板ポリゴンの流用は禁止。
- 歩行：四脚は移動中だけ対角脚を交互に運ぶ。停止時は足を止め、呼吸・尾の微動だけ継続。1マスの移動は描画補間し、ワープ移動を避ける。
- 飛行：飛竜は高頻度の羽ばたき、古竜・天竜は大翼の深いストロークと滑空に分ける。移動中は翼振幅・胴体の前傾と横揺れが変わる。実マスと衝突は変えない。
- パーツは生成時に統合し、同一種類・同一LOD・同一動作パーツの全個体をGPUインスタンスで描く。
- テクスチャは小型の共有微細粒子マップを使用。外部ライセンスに依存しないデータ駆動レシピ。

## 攻撃と鳴き声（v3）

| 種類 | 専用アクション | 攻撃予備時間 | 声 | 騎乗時の兵士ルート高さ |
| --- | --- | ---: | --- | ---: |
| 灰狼 | 下顎を開き前進・噛みつく | 0.19秒 | 遠吠え・吠え声 | 0.78 |
| 飛竜 | 翼を強く羽ばたかせて急襲・爪撃 | 0.24秒 | 甲高い叫声 | 1.17＋飛行高度 |
| 古竜 | 大翼・開口・火炎ブレス | 0.44秒 | 低い咆哮 | 2.38＋飛行高度 |
| 天竜 | 開口・長い溜め・天竜ブレス | 0.58秒 | 重厚な咆哮 | 3.10＋飛行高度 |
| **竜王** | 威嚇・開口・広範囲の火炎ブレス | 0.76秒 | 低く厚みのある咆哮 | **騎乗不可** |
| 軍馬 | 前脚を上げるいななき（観賞用、攻撃力なし） | 0.20秒 | いななき | 0.79 |

- 攻撃は「予備動作→判定→復帰」。攻撃開始時点ではHPを減らさず、攻撃予備時間の終了後に距離・生存を再検査して命中させる。移動・ダメージは `CombatActionRuntime` が担当し、描画は `creatureAttackProgress()` で同期する。
- 古竜の炎・天竜の秘術・竜王の広範囲火炎ブレスは口元からターゲットへ伸びる立体円錐を使用。着弾点ではライブラリの炎・秘術エフェクトを7枚連続表示し、地面の半径リングと組み合わせる。
- 鳴き声・攻撃声・被弾声は `combat-creature-sounds.js` が種ごとに独自合成する。音源素材のライセンスや日本語・外国語音声の混入がない。WebAudioはユーザー操作後に1個だけ生成・共有し、同時最大14音まで制限する（音源処理の標準上限16、戦場14）。
- 下顎を翼・脚・尾と同じ独立アニメーションパーツとして全種に用意。複数体は元メッシュを共有してGPUインスタンスの変形行列だけを更新する。
- `summon-showcase.html` の「鳴き声」「攻撃モーション」で、全種を1体ずつ聴覚・視覚確認できる。

## 騎乗（v3）

- 軍馬に加え、灰狼・飛竜・古竜・天竜にも兵士が乗れる。見た目に鞍・革装具を備える。灰狼は騎乗中に1.42倍へ拡大する。**竜王は二足・腕付きの人型なので騎乗不可**。
- 騎乗者は従来の兵士オブジェクトを維持する。召喚獣は独立したオブジェクトのまま `mountedBy` と兵士側 `mountId` だけで紐づける。兵士/オブジェクトを複製せず、乗り手と乗り物は同一マスを占める。
- 近くに空席の味方召喚獣がいる剣士・盾騎士・槍兵・弓兵・格闘家・召喚士はAIが騎乗可能。手動操作用には `mountObject(actor,creature)` と `dismountObject(actor)` を公開する。
- 騎乗時は乗り手の股関節・膝・腕を着座方向へ補正し、腰の位置を種別ごとの鞍に合わせる。飛行中は召喚獣の高度・上下動に兵士も追従し、移動速度補正を適用する。衣装・武器・人体を消去しない。
- 騎乗獣が倒れたらその兵士の `mountId` を解除する。下馬の着地点は空きマスのみ。下馬後は地上召喚獣が再び独立の衝突判定を持つ。
- 大軍戦のマス占有は兵士IDで予約する。戦闘不能/スキル移動で旧マスを解放する際、他兵士の予約を上書きしない。

## 描画品質と負荷

- 近距離: High LOD。各種1万〜3.4万頂点程度（部品合計）。立体鱗・毛束・翼指・装具まで表示する。
- v4.4.13: 灰狼の眉骨・耳内側・追加の歯列、竜の鼻孔・眼上稜・顔の触角・下顎牙・喉の装甲板・肩甲鱗、天竜の青白い宝石列を近距離モデルに追加。遠景LODと個体ごとのGPUインスタンス方式は維持する。
- ブレスは二重円錐に加え、炎・秘術のアニメーション粒子を射線方向へ分散。着弾点に衝撃波リング、火柱、飛散する破片を重ねる。VFXは `maxEffects` 上限で打ち止めにし、1000対1000で無制限増殖させない。
- 遠距離: Low LOD。不要な細部を除き、3,900〜6,000頂点程度を目安とする。
- 判定距離: 基準25ワールド単位に種族倍率を掛ける。戦場カメラ位置を参照して毎フレーム自動切替。
- 個体ごとにメッシュを生成しない。最大72個/種別をインスタンス配列に載せ、遠距離では高詳細部品を描かない。
- 翼・尾・脚はGPUインスタンス行列のみ更新し、主胴・鱗等は静的に統合する。
- 衝突・攻撃判定は COMBAT_OBJECT_SPECS と CombatActionRuntime を唯一の正とし、見た目メッシュからは再計算しない。

## 建物・橋の破壊（v4.4.13）

- 町の建物・城・石小屋・木橋・石橋を `describeDestructibleWorld` で実際の戦場に耐久値付き登録。城560、民家110、木橋115、石橋220を基準に種別で調整。
- 建物の壁・橋の端を含む実占有範囲へ、魔法・C4・ダイナマイト・召喚獣のブレス／攻撃が届くと耐久値が減り、0で破壊イベントを発行する。
- 破壊された建物は、その建物だけGPUバッチを隠し、立体瓦礫を配置。隣接する同じ形の家は消さない。町の壁の移動・射線判定を更新。
- 橋が崩れると元の橋・手すり・階段を取り外して崩れた橋を表示。橋のマスを通行不可にし、橋上の兵士を戦闘不能にして経路を再計算する。
- Worker大軍戦にも建物と橋の定義を転送し、破壊イベント・耐久値・通行マップ・遮蔽マップを同期。50対50と1000対1000で同じ破壊規則を使用する。
