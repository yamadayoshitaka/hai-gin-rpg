# 建物構造化：入口鍵・螺旋階段・3階建て王城

## データの責務

- `src/building-entry-locks.js`：外部入口のグレード、鍵Lv、通行権限だけを管理。室内扉と宝箱は対象外。
- `src/spiral-staircase.js`：円周上の踏面、中心柱、昇降位置と角度の純粋データ。
- `src/building-structure.js`：外装カタログに対する階数・踊り場・階段BOMと3D形状。形状を再利用して重複メッシュを削減。
- `src/world-blueprints.js`：旧探索マップでも階数・入口・階段を共通建物データに格納。
- `src/interior-areas.js`：隣接階のみを結ぶ往復ポータル。2階を持つ城の中間階には上下両方のリンクが存在。

## レヴナ王城

1. 1階：大広間・宝物庫。城の外部入口は1階の南側だけ。
2. 2階：玉座の間。1→2階と2→3階の螺旋階段を接続。
3. 3階：王室・王立資料室。3→2階の階段で降りられる。

軍団戦のオブジェクト `castle_001` は `root.userData.structure.floors.length===3`。
1階・2階・3階の床構造は保持し、軍団戦中に上層床が兵士を覆わないよう表示は初期オフ。階段の踏面と手すりは3D表示される。

## 入口だけの鍵

| 建物 | 鍵レベル |
| --- | ---: |
| 民家・石小屋 | 1 |
| 武器屋・道具屋・宿屋 | 2 |
| 教会・豪商の屋敷 | 3 |
| 貴族・領主の屋敷 | 4 |
| 王城 | 5 |

店舗などは通常営業中に入室可能。王城のLv.5錠は通行許可 `royal-visitor` を認め、現在の物語導線を妨げない。
古い探索画面では鍵判定を実際の建物入室処理へ接続。現在の軍団戦画面には建物への入室操作自体がないため、入口グレードと鍵レベルを建物BOMに保持し、将来の入室システムで利用する。

## 検証

`npm run test:spiral-buildings`、`npm run test:building-entry-locks` と `npm run test:all`。
Android端末での階段歩行・城内カメラ・上層床表示については、ブラウザ実機での視覚確認が別途必要。
