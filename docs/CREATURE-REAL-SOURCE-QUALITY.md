# 2026-11-16｜全108体の原型を「リアルベース」に作り直すための制作・品質契約

## 合格と数値の区別

画面に表示される三角形・頂点・メッシュ数はモデルデータ量を示すだけで、写実性を証明しない。低品質の球体・チューブを4分割/細分化しても、実物の頭蓋骨・肩甲骨・関節・表皮情報は追加されない。

- **現段階**：50種の敵＋同種召喚50種＋専用8種、計108体の生成器と閲覧機能がある。モデルの制作・審査は未完了。
- **今回の実際の造形差分**：現行ゲームのソース形状で、四足・鳥・虫/蜘蛛・海蛇の主胴体の球体/均一チューブを、前後に異なる寸法の軸方向断面メッシュへ置換。m020とm048の胴・尾節を独立した連続曲面に変更。これはプロシージャル原型の改善であり、FF級の完成GLBやフォトスキャンではない。
- **保護**：m005・m006とその召喚版の既存モデルは造形・採用対象外。人型m015も既存頭部・鳥体型を保持。人型16種と専用人型召喚は独立した人型品質改善フローを使う。
- **品質ゲート**：src/creature-real-source-audit.js が全108体の「現段階」「種族固有の解剖設計」「未認定の理由」を持つ。合格数は実在証拠が確認されるまで0とする。

## 原型改修の必須工程（品質回帰バッチにも適用）

1. 対象IDの定義・種族・能力・既存アセット採用/保護フラグを参照し、**正・側・背・斜め4方向の同一個体基準画**と解剖学的アナログを確定。別の生物の見本モデルを色だけ変えて流用しない。
2. 鱗・毛皮・羽・角・牙・眼球・顎・首・脚・筋肉・翼・ヒレを各動物の骨格で正しく配置。**既存メッシュの細分化・頂点数増加だけの変更を「写実化」と呼ばない。**
3. ソース原型はGLB/Blend等の実編集可能アセットとして保存。必要ならBlenderヘッドレス生成とトポロジー検証をGitHub Actionsで行う。画像2Dやプロンプトだけで原型完了としない。
4. PBRのBaseColor / Normal / Roughness / AO等を部位別に適用。原本・作者・取得元・利用規約・商用利用可否・帰属表示条件を素材単位で記録する。CC0等は個別に確認。
5. 生物別の骨格/ジョイントで idle, walk, run, attack, roar, hit, defeat の実動作を実装し、歩行時の滑走・肢体空中浮き・頭/胴の裂けを検査。**ボーン0の静的GLB書き出しはモーション完成に数えない。**
6. 参照2Dと実3Dの同角度レンダリングを4方向で比較。人間による「プラスチック感・継ぎ目・解剖学的破綻・写実不足」のチェックを含める。解像度やFPSだけでは認定しない。
7. 承認済み高密度sourceからretopo → normal/AO bake → near/mid/far LOD → GLB圧縮の実ファイルを生成し、近景ビジュアルを比較。最終の1000対1000戦闘に高密度sourceを直接使わない。
8. テスト→コードと新規実モデルファイルのコミット→PR/CI→本編登録・デプロイまで通過して初めてバッチ完了と数える。基準画台帳だけの更新、単なる調査、未使用3DをアップするだけのPRは品質完了に数えない。

## 種族別の実原型

- 犬・狼 / 猫：頭骨、肩甲骨、筋膜、脚の関節、歩容、体表毛。別種の猫の素体を共通化し過ぎない。
- 鳥 / グリフォン：肩/肘/手首の翼骨格、羽列・胸骨・羽ばたき。グリフォンは獅子胴との専用接合。
- 爬虫・ドラゴン・海蛇：顎関節・長い頸椎・尾椎、爬虫類鱗、蛇行・水泳、角・鰭の根元。m020は他のヒドラと違う長い海竜骨格。
- 甲虫 / 蜘蛛：昆虫6脚と蜘蛛8脚を厳守。節・関節・甲殻・牙をそれぞれ定義する。
- スライム / タコ / クラーケン：水分・粘液・透明感、吸盤、軟体の変形と遊泳を優先する。
- 不死 / ゴーレム / 魔族 / 人型召喚：現行の人間素体を基準に、衣服・骨露出・装甲・髪・翼・角を正しく接合し、浮き・貫通をなくす。
