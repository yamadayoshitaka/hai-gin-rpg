# 灰銀のレゾナンス — 全面置換の受入条件 (v41.8 時点)

## 原則
ゲーム実行クラスは data -> result の純粋な変換・描画アダプタ。エリア、建物、部屋、家具、NPC、装備、素材、部品、ASSY、重量、干渉、アニメ状態の正本は一箇所の宣言データ。旧方式を表示の fallback として残したまま「完了」と呼ばない。既存の操作・戦闘・店・宿・階段・AI会話を後退させない。

## コミット完了ルール
「作った」ではなく「コードを反映→自動テスト合格→Pages 公開→Android 画面で確認→受入基準達成」までを完了として扱う。最優先は人物の一体型スキン化。人物表示と動作を先に受け入れ可能にし、同方式を NPC に横展開する。
