# 灰銀のレゾナンス — 戦闘UI・移動・高所AI 実装指示書 v4.6.1

## 目的
50対50／1000対1000の操作・移動・騎乗・高所戦術を、既存のマス占有・当たり判定・衣装・物理処理を壊さずに改善する。Androidブラウザでの動作を優先し、2000人表示時はGPUインスタンス＋Workerによる軽量化を維持する。

## 1. 通常移動は基本ダッシュ
- 屋外・交戦時の標準移動をダッシュとする。50対50の実モデルは `run` モーション、1000対1000のGPUモデルもダッシュ歩行位相を使う。
- 50対50の移動係数を `.66` から `.88` へ、1000対1000の格子移動係数を `.52` から `.70` へ変更する。
- 敵が目前・梯子・階段・屋内の慎重な移動・扉前の待機は例外。衝突回避、占有マス、橋・水面判定は変更しない。
- マス移動の終了で毎回アイドルモーションへ切り替えない。見た目の歩幅は移動距離から同期する。
- 検収: 50対50でマス境界に瞬間停止がなく、1000対1000で足が滑りにくい。既存の移動経路テストを通過。

## 2. 騎乗モデルの同化を禁止
- 人体モデルと乗り物モデルは常に別オブジェクト／別HP。メッシュの結合やスケールによる押し込みは禁止。
- 馬・狼・飛竜・古竜・天竜それぞれの鞍／背中基準座標を用意する。人体骨格には騎乗姿勢（腿・膝）を適用し、腰が鞍に合うよう上下と前後を補正する。
- 騎乗中、乗り物の旋回は乗り手の向きに一致。乗り手の攻撃方向だけで馬の身体を急回転させない。
- 50対50の詳細人物と1000対1000のGPU人物には同じ座標規約を適用する。
- 検収: 人の胴体が馬・召喚獣の胴体に埋まらず、立ち乗り／首へのめり込み／乗り物と人物の分離がない。

## 3. 右下の命令メニューは部隊選択時のみ表示
- 通常時は画面左下のレーダーのみ表示し、右下の部隊セレクト・号令・HPパネルは隠す。戦場の視認範囲を広げる。
- 味方の青い隊列ラベルまたはレーダー上の味方部隊をタップすると、その部隊の指揮メニューを開く。
- メニュー: 号令／行き先／命令／HP／使用条件を満たすUR軍師ワープ。戻るで閉じる。
- 指揮メニューの開閉は戦闘を一時停止しない。敵部隊ラベルから味方命令は開かない。
- 検収: 初期状態で右下の大型命令枠がなく、ラベル押下時だけ表示され、戻るで消える。

## 4. 軍師の戦況メッセージをタップしたら軍師を映す
- 下部の顔＋戦況メッセージにタップ／Enter・Spaceで反応する操作を付ける。
- タップされた報告に `squadId` がある場合、その部隊の軍師の現在位置を探しズーム・追従する。軍師死亡時は最後の位置を使う。
- 50対50など軍師が独立したユニットでない戦闘は、該当部隊の代表位置へフォールバック。別部隊への誤フォーカスは禁止。
- 「履歴」ボタンの押下はカメラ移動しない。タップで移動したカメラは自動で戻さない（イベントによる自動注目は一定時間で戻す）。
- 検収: 軍師死亡通知／危険通知をタップすると正しい部隊を映し、履歴ボタンは通常どおり開閉する。

## 5. 忍者・シーフ・弓使いは高所優先
- 最優先: 射撃・投擲・奇襲に使える、安全で通行可能な高い場所。
- 50対50: 周辺建造物の階段・上階・窓を確認し、近距離にいる忍者・シーフ・弓使いの移動候補を自動生成。負荷軽減のため検索間隔を制限し、毎回1人ずつ出発させる。
- 弓使い: 上階からの射程10倍／威力4倍（1階上がるごとに累乗）。忍者の手裏剣も同様。忍者の手裏剣は命中地点周囲への範囲ダメージ。
- シーフ: 上階では投げナイフ（通常の高所補正）を選び、地上では通常の近接・側面戦術を維持する。
- 1000対1000: 初期地形の高さを Float32Array に一度だけ抽出し Worker に転送。弓使い・忍者・シーフは隣接する合法マスに高い地点があれば評価を上げる。危険時／明示の部隊命令は優先し、渋滞を増やさない。
- 1000対1000の高所AIは現状 **地形高低差のみ**。屋上への3D梯子／鉤縄通行を大軍全員に反映するには階層ナビゲーションの別対応が必要で、実装済みと誤認しない。
- 検収: 高い地形を優先する純粋関数のテストに合格し、50対50の窓射撃・高所での手裏剣／投げナイフを確認。

## 追加ルール：召喚士・召喚獣・乗り手
- 召喚獣の `ownerId` は召喚士、`mountedBy` は乗っている兵士。これらは同一人物とは限らない。
- **召喚獣が受けた実HP減少量の50％は召喚士だけに連動**。乗り手に連動ダメージはない。
- 召喚士への実HP減少量の50％は自分の召喚獣へ連動。無限再帰しない。
- 召喚獣が消滅し騎乗者がいれば、騎乗者だけに落下ダメージと落下演出。召喚士にはその落下ダメージを連動しない。
- **馬と騎乗者のHPは連動しない**。騎乗中の移動・攻撃倍率とHP連動は別処理。
- 検収: 第三者騎乗・召喚主戦闘不能・召喚獣戦闘不能・馬被弾をそれぞれ自動テストする。

1. `node qa/battle-five-enhancements.test.mjs` を通過させる。
2. `npm run test:battle` と既存のUI／職業／騎乗／Workerの回帰テストを通過させる。
3. CI公開を成功させ、画面上のバージョンを v4.6.1 に合わせる。
4. 実機のFPS／人物騎乗姿勢／UI操作については、ブラウザテスト成功とユーザー端末での目視確認を区別する。
