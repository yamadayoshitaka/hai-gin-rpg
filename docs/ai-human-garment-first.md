# 剣士 AI人体＋AI衣装：衣装基準でフィット・肌削除

## 2026-11-08 の実際の状況
- **現行の完成剣士**：`buildRiggedJobOutfit({job:'job01'})` を使う本番ゲームと同系統のモデル。65骨、衣装・装備111メッシュ、約97,340三角形（2026-11-07 実ブラウザQA）。
- **覆われた肌の削除**：既存の `deriveGarmentCoverage` → `clipBodyToGarment` がデフォルトON。現行剣士の検証結果では6,210三角形を隠す。顔・首・指は保護対象。
- **低精細な無料鎧**：4,010三角形。品質面で現行剣士より劣るため、比較画面の初期表示には使用しない。ファイル選択時のみ検証可。
- **AI生成の人体と鎧**：外部サービスでGLBが生成されたものはまだない。生成したと誤認させず、AI人体とAI衣装を別カテゴリで分離する。
- **ゲーム正式採用**：AI人体は骨のリギング、歩行・攻撃のリターゲット、商用利用許可、外形・肌・顔・指の目視検証が終わるまで禁止。

## 機構
1. AIで **男性7頭身の素体** を、ヘア・顔・指・足・背面を確認できる単体GLBとして生成する。
2. AIで **衣装・鎧** を独立GLBとして生成する（前面・背面・肩・脚・手首を含む）。
3. **衣装の寸法・中心・前後方向を基準**として人体のみを合わせる：`autoFitNudeToGarment`。衣装を人体に合わせて潰すのではない。
4. 衣装の近接表面／領域＋人体の骨重みから、覆われた皮膚だけを **非破壊のインデックスマスク**でカット：`maskImportedNude`。未リギング人体の場合は保守的な表面近接マスクを用い、顔・首・手を守る。
5. 素体の肌材質は `ai-human-skin-preview.js`、白い鎧は `ai-swordsman-steel-finish.js` で仮PBR化する。どちらも形状や顔の精細度を自動では改善しない。
6. 正面・側面・背面を確認し、フィット、ボーン、テクスチャ、二重脚、手甲浮き、肌の貫通、露出を検査。品質が現行以下なら不採用。
7. 最後に必要ならリギング・人体面のトリム・テクスチャベイク・最適化を行いゲームへ投入する。比較時点では現行モデルを自動置換しない。
