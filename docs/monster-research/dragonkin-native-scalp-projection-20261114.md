# 女性人型龍王・頭頂の「紫色のタマネギ」状装甲の廃止

2026-11-14 15:49の画像では、v4.5.12でも頭頂部に半球状の大きな別部品、渦巻きの段差、橙色の露出箇所が残っていた。原因は `createDragonkinCranialShellGeometry` が元のGLBの頭皮寸法を推定した別の楕円体を生成しており、実際の三角形の表面には密着していないこと。

`src/dragonkin-native-scalp.js` は、実際の女性型 Quaternius の可視 `SkinnedMesh` からHeadボーンへのウェイト0.73以上の頂点を取得し、モデル上向きに補正済みの頭骨アタッチメント座標へ投影する。両眼・眉・髪・不可視ヘルメットは除外し、頭頂半分（眉より上）の面だけで三角形を組み立てる。表面から法線方向へ約3mmずらし、鱗色で薄く覆う。**元の顔・スキニング・共通モデルは変更しない。** 対象は `dragonkin_female` のみ。実モデルに頭皮の有効三角形が十分存在しない場合は、従来のヘッドフィット楕円体へ安全にフォールバックする。

`qa/dragonkin-native-scalp-regression.test.mjs` はHeadボーンの骨重量・UV・採寸・頭頂境界・非巨大化・元の三角形接続を模したスキンメッシュで検証。CIに接続し、図鑑・召喚獣鑑賞のキャッシュをv4.5.14へ更新。

**未検証事項:** 本物のGLBにおける有効三角形数、プレビュー上の服・角・顔との交差、実機での写真の見え方はブラウザとAndroidで追加確認が必要。もし本GLBのHead骨ウェイトが通常と異なる場合は従来帽子形状がフォールバックするため、診断`dragonCraniumNativeTopology`/ `dragonNativeScalpTriangles`がどちらの方式で描画されたか確認できる。
