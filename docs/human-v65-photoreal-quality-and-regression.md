# 灰銀のレゾナンス｜人モデル v65 実写寄り造形・回帰修正指示書

作成日：2026-11-15  
状態：段階的実装／視覚品質の最終合否は実機3Dスクリーンショットで判定する  
対象：女性・男性の独立顔モデル、3D髪型、全顔タイプ（男女各16）、全表情（22）、人体・衣装への接続。元GLBとゲームの保存済み顔・髪・体型の互換性を維持する。

## 1. 診断と品質目標
現在の `src/face-scalp-wig.js` と `src/face-wig-ornaments-v49.js` は頭皮に沿う束と細いチューブを使用するが、横顔・頭頂・結び目では束の統一感と毛流れが不足する。 `src/face-feature-meshes.js` は平面テクスチャではなく曲面の白目・虹彩・瞳孔を作るが、頂点色によるハイライトが中心で、実写級の角膜・涙液の表現までは未到達。 `src/independent-face-masters.js` は既存顔の頂点を変形して鼻筋・鼻先を整えるが、小鼻、鼻柱、鼻孔縁の断面は単純な局所マスクである。 `src/face-expression-animation-v48.js` は22表情で眉・まぶた・頬・口・顎を変形するが、鼻翼・眼輪筋・頬筋の相互作用は限定的。

**目的**：実写「風」を段階的に改善し、髪の孤立・穴、眼球の浮き・斜視、横顔の鼻の不自然さ、表情の筋肉不整合を可視的に削減する。商用高精度顔アセットや実写真テクスチャを未導入の現状で「実写級を達成」とは主張しない。

## 2. 髪型改善
- カタログは `src/face-wig-styles.js`、毛流れは `src/face-hair-groom-v50.js` を仕様の正本とする。髪型ID、前髪、束長、結び位置の対応を自動検証する。
- サイドポニーはv64の**実頭皮頂点アンカー**を維持。14本の大束を崩さず、単一の追加細毛ファイバージオメトリに微細な束を結合して、点状の毛根・棒状の独立パーツ・大きすぎる光沢を減らす。
- 頭頂部・分け目・前髪・側頭部・うなじを正面、45°、真横、後頭部、頭頂部で撮影。**孤立する髪、肌が露出する不要な穴、貫通**は重大不具合。
- 物理演算は初回品質回帰では不要。髪密度やディテール追加でAndroidのFPS・描画負荷を悪化させない（束ごとのドローコールを増やすより結合を優先）。

## 3. 目・角膜・虹彩
- `src/face-feature-meshes.js` の曲面眼球の奥行き、眼窩に沿う上下まぶた、まつ毛のカールと間隔は維持。黒目をさらに前へ押し出す方式は禁止。
- 虹彩繊維の多周波模様、瞳孔周囲の自然な色遷移、暗い輪郭（limbal ring）と小さな反射を改善。白目は純白ではなく僅かな色差と上まぶた側の接触影。瞳孔と虹彩は同じ視線オフセットを使う。
- まぶたの開閉・瞬き・眼球・まつ毛の追従を正面および横で実画像評価。顔タイプ変更後も虹彩の外周がまぶたを貫通しない。
- 既存まつ毛の先細りメッシュを保持し、透明な板ポリゴンや黒い太線を上から貼らない。

## 4. 鼻・顔表面
- `src/independent-face-masters.js` の **元顔メッシュのみ**を対象とし、鼻根・鼻筋・鼻先・鼻翼・鼻柱の曲率を滑らかに変える。鼻を別球で追加しない。鼻孔を黒い点・穴として貼り込む処理は禁止。
- 顔半幅28%より外側の頬・目・耳の変形はゼロ。鼻先・小鼻の改変は左右対称な小さな値に抑え、鼻筋を尖らせすぎない。
- 男性・女性、16顔タイプ、20代・高年齢層それぞれで前／45°／横の影と鼻先・口元の関係を確認。既存の鼻・口・輪郭プリセットを壊さない。
- 若年のシワ係数はゼロを維持。陰影・肌の見え方は物理的な光と緩やかな凹凸で表し、線を直接書き込まない。

## 5. 表情
- `FACE_EXPRESSIONS` の22種類とそのIDを維持し、各表情の眉、眼輪筋、頬、鼻翼、唇、顎の連動を改善する。
- 笑顔で頬が上がり、怒り・怒鳴りで眉・鼻根・鼻翼が連動し、驚きで瞼と顎が連動する。鼻翼の動きは小さく、20代の皺を彫り込まない。
- 表情は元の顔頂点スナップショットから毎回作成し、切り替え50回後でも変形が蓄積しないこと。瞬きと口パク（日本語音声の既存系統）は維持。

## 6. 機能と編集画面
- `character-face-catalog.html` の既存32完成顔、22表情、キャラクター管理は継続し、同一の実3Dプレビューで比較可能にする。
- 元の保存済み顔プリセット・髪型カタログIDを変えない。プレビューは保存済み設定を上書きしない。衣装で覆った肌と生身の首・胴体の継ぎ目は v62/v63 の仕様を守る。

## 7. 回帰ゲートと証拠
1. 静的構造テスト：髪のアンカーと微細毛の統合、鼻の範囲制限、虹彩の単調なリム暗化、ニュートラル表情ゼロ変形、22表情の一意性。
2. 既存テスト：v59/v62首接合、v63衣装の可逆マスク、v64の32顔・22表情、全職業衣装、既存顔・髪モデル。
3. モバイルChromium（幅460程度）で男女、正面・45°・横・後頭部・頭頂、サイドポニー、笑顔・怒り・泣き・驚き・口パク・瞬きを撮影して比較。
4. ゲーム全体：戦闘1000×1000・町・スタジオのロード・FPS回帰を監視。新たなコスト・課金モデルなしで実装。
5. GitHub Actionsが成功したことと **実画像が自然であること** を別々に承認。最終の視覚品質が未達ならPRを保持して理由を明記。ユーザーが明示的に暫定公開を求めた場合は現状と残欠点を提示する。

## 8. 段階と完了定義
- 第1段階：眼球・鼻・表情の連続曲面の改善、髪束ディテールの結合。
- 第2段階：顔タイプ・髪型カタログの全組合せから代表セットを画像化し回帰。
- 第3段階：スクリーンショットの合否・パフォーマンス・保存互換性まで確認し、マージ・公開。

「実写級」達成を主張するには、写真基準の高解像度皮膚テクスチャ、物理的な角膜層、アーティスト製の高品質フェイスメッシュ／毛髪の導入が追加で必要。v65は既存無料のThree.js資産で可能な範囲の改善を最優先とする。
