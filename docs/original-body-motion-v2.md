# 全身アクション工房 v2 独自モーション設計

## 前提
既存男女別65骨のスキン人体と体型設定は維持する。既存クリップ、BVH、外部モーション、sampleHumanClipは再生しない。本仕様のキー姿勢のみを動作源とする。座標はY上、Z前、左右は人物自身の左右。角度は度、時間は秒。左右の鏡像で歩行周期を構成する。骨の長さは既存人体から取得し変更しない。

## 動作設計
- 待機: 重心を中央に保ち、胸郭・肘を小幅で動かす。
- 歩行: 踵接地→荷重→支持→蹴り出し→遊脚。左右位相を半周期ずらす。両足の支持が重なる期間を持つ。
- 走行: 接地→圧縮→蹴り出し→空中→次の接地。歩行の単純高速化はしない。
- ジャンプ: 予備屈曲→伸展→空中→着地吸収→復帰。
- 座る/しゃがむ: 股関節・膝・体幹を協調させる。座るは椅子を表示する。
- お辞儀: 腰・胸郭の前傾→保持→復帰。
- 手を振る: 肩を上げ、肘を屈曲し、手首を往復する。
- パンチ: 構え→引き→伸展→回収。肘の過伸展を防ぐ。
- 物を握る/拾う: 開手→手を対象に接近→指を閉じる→保持。拾うでは股関節・膝を屈曲して手を下げ、持ち上げる。手の位置は手首の二節IKで補正する。物体は接触イベントで保持に移行する。解除後の再取得は動作を再開した場合のみ。
- 指差し: 人差し指を伸ばし、他指を曲げる。
- 手を開閉: 手指各3関節に独自の屈曲角を設定する。

## 個体差
年代・体型は独立パラメータ。高齢はテンポ、歩幅、屈曲幅、体幹前傾を調整する。太めは脚・腕の可動域と間隔を補正する。性別では骨長に従って同じ設計を適用し、性別だけで能力や歩行様式を固定しない。

## 品質ゲート
全動作の時刻、有限性、関節角範囲、周期端点、左右支持位相、走行の空中区間、把持イベントの順序を自動検査する。男女モデルの読み込み、関節・手指の変化と持ち物の保持/解除をブラウザで確認する。接地はプレビュー内の支持足補正であり、床・指・物体のメッシュ衝突、リアルな物理、モーションキャプチャ級品質は別工程。E106の顔統合は対象外。
