## 黒目の円形・自然な瞳
`src/face-feature-meshes.js`：
- 従来の白目楕円 `x=1.18`、`y=.79` の比率を虹彩/瞳孔の2D投影にもかけてしまい、黒目が楕円になる問題を修正。
- 眼球（楕円体）はそのまま、正面から見た虹彩・瞳孔を正円にし、3D深度は楕円体方程式から求める。
- 虹彩の外周リングと細かい放射状の色変化を頂点色で追加。既存まぶた、眉、アイライン連動・男女GLB書き出しを維持。

## 独立した顔と実際の女性胴体を接続
`src/face-body-assembly.js`（新規）：
- `realistic-body-female.glb` の実体に、保存済み独立顔 `realistic-head-animation.glb` のクローンを身長実寸と頭部BBOXでフィット。
- 元の胴体の頭を「見かけ上隠す」のではなく、クローンの三角形インデックスを首位置で除き、GLB書き出しにも重複した頭を含めない。元の両GLBは改変しない。
- 参照衣装の `viking-outfit-source.glb` は暫定的な色替え表示。原画衣装と同じ形状という主張はしない。
- 髪用の胴体接触判定は、取り込んだ女性胴体および衣装の実三角形を横/縦の32×64領域へ索引化し、該当位置の最前面と最後面のZを補間する。髪束が内側に入った場合は近い側の表面の外へ補正。
- 既存の顔/頭皮接触と肩/胸カプセル判定も併用。静止・現在のプレビュー姿勢での形状補正であり、将来のスケルトンアニメーション時の完全貫通防止保証ではない。

## 新しい実3D確認画面

- 独立ヅラのIDを切替可能。

- 旧`face-mesh-studio.html`からリンク追加。旧画面の男女保存顔、スライダー、単独ヅラ出力は不変。

- 単体：黒目・虹彩のX/Y投影直径比（誤差1.5%以下）、3D眼球深度、保存頭部の元データ非破壊、首より上の元胴体頭部三角形削除、実胴体接触点の押し出し。
