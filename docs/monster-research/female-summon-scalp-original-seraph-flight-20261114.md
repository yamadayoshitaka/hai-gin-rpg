# 女性型召喚獣3体の頭頂被覆・天使の羽と飛行（実機スクリーンショット回帰）

## 受領した画像
2026-11-14 15:49頃の3枚を確認した。森の精霊弓士は頭頂の中心に大きな白い円形の地肌/土台が見え、周辺だけ濃い髪が垂れる。龍王はピンク紫色の頭頂が大きな独立した塊のように見える。光翼の守護天使は上から見ると金髪の中央に桃色の大きな露出箇所があり、簡易羽根は薄い白い直線板を9枚重ねたようなシルエットで元の召喚獣の羽根より劣る。ユーザーは天使の飛行も要求している。

## 根本原因
- `src/monster-humanoid-hair.js` の長髪ストランドは初期極角が常に0.40rad以上で、**頭頂中心の半径約4cmに独立した毛根がゼロ**。ベースのカラーメッシュがむき出しとなる。色の薄い天使/森精霊ほど白い頭皮のように強調される。
- `src/female-summon-costumes.js` は光翼の守護天使に片翼9本の簡易羽を生成する。元の高品質な `src/creature-summon-humanoid-anatomy.js` には片翼82枚（主翼34+覆羽29+小羽19）の重なり、弧状骨、個別色と高密度の先端輪郭を持つ羽根モデルが既にあるが、女性人型への切替で非表示になる。
- `summon-showcase.html` は女性召喚獣を地面と同じ y=0 に置くため、翼があっても飛行しない。

## 修正方針と実装
1. 髪のセンター0.02〜0.47radに放射状の追加ストランド（高LOD168本／低LOD48本）を生成。頭皮メッシュの下地をわずかに暗くマットにし、白く光る円盤を抑える。元GLB/スケルトンに手を加えない。
2. 女性天使の簡易羽を撤去し、元の光翼の守護天使と**同じ `buildCombatObjectGeometry('seraph_guardian')` の原版 `wingL/wingR`** を抽出して使う。元の頂点色・羽根形状を維持し、採用しない元の胴体・顔・脚は直ちに破棄する。左右の羽は本物の胸骨へ付けた独立ピボットに固定し、アニメーションで周期的に羽ばたく。
3. 女性天使は鑑賞画面で地面から約0.65〜0.87m浮遊し、ゆっくり上下へ変化する。移動操作時も浮遊を保持。ロード完了時のカメラは浮いた全身を見られるよう高さを変更する。戦闘中の元のGPU召喚獣・その他の獣や竜の動きは変更しない。
4. 龍王の頭頂は現行の第2段階の修正後も視覚上未達。今回の画像を未解決の視覚回帰課題として記録し、次に実頭蓋メッシュの直接投影を検討する。**今回のパッチで龍王の頭頂まで完成したとは言わない。**
