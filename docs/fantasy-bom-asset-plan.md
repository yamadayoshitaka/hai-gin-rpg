# 灰銀のレゾナンス — 汎用ファンタジーBOM素材導入方針

## 状況
これは**調査済み候補の台帳**。素材本体は未取得・未変換・未搭載。ライセンスとバイナリを検証するまで既存キャラクター描画は切り替えない。

## 共通の基準
- 人体: 7〜8頭身を想定した成人、少年、体格差。頭部・髪・顔・肌・服・鎧・腕・足・手・靴・小物は可変部品。
- 世界観: ドラクエ/FFそのもののキャラクター、商標、モデルを複製せず、独自の王道JRPGファンタジー表現を目指す。
- BOM: **source asset -> normalized part -> character/building preset -> scene instance**。実体(メッシュ、UV、マテリアル、スケルトン)と意味属性(職業、勢力、NPC/PC、店種)を分離。
- 装備: slot=hair/head/face/chest/arms/hands/legs/feet/cape/mainHand/offHand/back。socketまたは同一スケルトンのskinに装着する。重複する身体メッシュは隠す。
- NPC: 村人、商人、宿屋、武器屋、防具屋、兵士、騎士、魔法使い、僧侶、盗賊、貴族、王族、子供、老人をプリセットで表現。
- 追加対象: 魔物(スライムに似せない独自デザイン、獣、ゴーレム、竜、亡霊など)、動物、建築、家具、木、自然、小物。素材の有無はカタログで個別管理。
- モデル規格: glTF 2.0/GLBに正規化、Y-up、m単位、PBRマテリアル、ボーン規約、アニメーションクリップ規約、LOD/カリング、共有テクスチャ。
- 質: 遠景のNPCは軽量化。主人公や会話相手は近距離用の顔・髪・服に手をかける。異なる作者のアセットの見た目は自動では揃わない。

## 導入順序
1. Quaternius Universal Base Charactersを一体だけ隔離プレビューし、頭身、スキニング、描画サイズ、fpsを検証する。
2. Modular Character Outfits Fantasyから胴・頭・腕・脚の着せ替え、3色差し替えを検証。ボーン互換と衣装貫通は自動・画像両検査。
3. Universal Animation Libraryのidle/walk/run/attack/hit/guardとretargetを接続。Root motionとゲーム移動ロジックの二重移動を防ぐ。
4. 合格後、NPC職業プリセットをデータ追加で量産。主人公以外にはランダム外見とLOD導入。
5. Village/Propsで町・家・店・屋内を同一部品BOMに統一。
6. FF寄りの等身や顔を重視する場合は、MakeHuman/MPFBのCC0コア資産による別系統の体型生成パイプラインを比較。ライセンスの異なる外部追加アセットは個別確認。

## 必須検証
- すべてのGLBでロード完了、texture missingなし、スケルトンとアニメ再生、法線/UV不良なし。
- 主人公/NPCの置換前後のスクリーンショットを同じ位置・同じカメラで比較。
- 当たり判定と描画メッシュの位置同期。室内入室、室外退出、戦闘、手持ち武器とのアニメ同期。
- FPSとドローコール、三角形数、テクスチャメモリを端末/PCで監視。
- 元のゲーム・HUD・BOMアーキテクチャテストを退行させない。
- 出典URL・作者・各ファイルのライセンス・checksum・導入日・source versionを資産台帳に記録。

## ライセンス注意
Quaternius・KayKitの該当無料素材にはCC0表記があるが無料版と有料Source版で収録数が異なる。
GitHubミラーだけで判断せず公式のライセンスを保存。MakeHuman/MPFBは**コア素材CC0とツールのGPL系コードを混同しない**。
外部作品「ドラゴンクエスト」「ファイナルファンタジー」の実際のキャラクターデータは収集対象外。

候補の機械可読データ: `data/asset-source-catalog.json`。
