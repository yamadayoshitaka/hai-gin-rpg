# 全ステージ・オブジェクト基準画と3D品質回帰

- 200 story stages + 53 catalog objects are in the canonical inventory generated by scripts/world-quality-catalog.mjs.
- Master images are *aspirational 2D references*, not rendered game improvements.
- Cloudflare Free may be used only with verified existing GitHub Secrets/Variables, and no paid fallback.
- Each asset gets a reference image and immutable hash proof. Objects get actual browser WebGL captures for a fixed camera, plus bounded roughness parameter experiments.
- Python image-proxy scores select a *candidate only*, never a photorealism certification.
- Candidate PBR changes are kept in world/photoreal-regression-review as a draft PR; they do not reach main until reviewed/merged.
- 200 stage QA captures are tied to scenePreset and must validate the exact selected stage; they do not imply all 200 maps are handcrafted or unique.
- No automatic geometry or collision changes, and no auto merges.
- Logs and history: GitHub Actions; operational dashboard: batch-monitor.html.
