# 人型モンスター・召喚獣：ゴシックファンタジー衣装基準 v1

2026-11-14 の会話で確認された6体のイメージ（天使、森の精霊、竜王、サキュバス、吸血鬼、ガーゴイル）を**衣装構成・配色・シルエットの参照**として採用する。画像そのものの写真品質を今のポリゴン／テクスチャで達成したと主張するものではない。

## 全人型の必須原則

- モデルの元は現行の男女キャラクターGLB。元の骨格・顔や衣装マテリアルを変更しない
- **下着のみ・裸の胸／腹が見える暫定状態をデフォルトの完成品扱いにしない**。胴体を包む立体衣装・腰に追従する前後360度の腰衣装・腕袖・必要な脚装備を必須とする
- 胸の服は胸骨、長衣・スカートは骨盤、袖は上腕、手甲は前腕、脚装備はすねに固定する。口や翼の前後方向は共通基準に合わせる
- 近接／遠景の両LODでUV・法線・正しい頂点と関節追従を維持
- 背面の羽根・翼・尻尾・髪は維持し、胴体を覆う衣装がそれらの根元と干渉しないようにする

## 人型全体への水平展開

- 死霊騎士・黒騎兵：胸甲、鎧袖、腰布・脚甲、破れたマント
- デーモン／インプ：鎧または戦装束の胸、腰・脚を完全に覆う
- 鴉天狗：和風・儀礼風の衣装（鳥の嘴と羽根を保つ）
- リッチ：下までのローブ
- 骸骨剣士：胸の儀礼布、脚甲
- ミイラ：既存の幅広包帯一式を保持（新しい貴族衣装を無理に被せない）
- 五種ゴーレム：独自の全身鉱物甲冑を維持
