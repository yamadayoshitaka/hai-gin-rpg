# 獣系モンスター獣人型 3Dモデル制作仕様（第一弾・2026-11-15）

## 目的・方針
『灰銀のレゾナンス』図鑑の獣系に、既存四足モデルとは別に獣人型（二足型）の確認・選択バリエーションを追加する。

- **原型は獣。** 人間型の Superhero_Male/Female GLB に犬耳だけを足す方法は採用しない
- 元の獣の頭蓋骨・口吻・眼・耳・顎・牙・毛・尻尾・四足の先端の立体造形を流用
- 人モデル開発で使用した「胴体・骨盤・肩・腕・前腕・手・腿・膝・すね・足の部品化」を獣体へ適用
- 元の四足型は絶対に上書きせず、図鑑で「元の四足型／獣人型・二足（試作）」を選ぶ
- 第一段階は鑑賞専用。戦闘の物理判定、召喚サイズ、ナビゲーション、NPCコマンド、元のGLBは変えない

## 骨格（第一弾）
- 骨盤（pelvis）、胸郭（torso）、頭部（head）、顎（jaw）、尻尾（tail）
- 左右肩関節（armL/R）、肘・前腕（lowerArmL/R）、掌（handL/R）
- 左右股関節（legL/R）、膝・脛（lowerLegL/R）、踵・足先（footL/R）
- 左右の掌と足裏には、**元の狼の paw と元の足の先端をそのまま取り付ける**
- 適用モーション：待機、歩行、走行、通常攻撃、固有技、咆哮、防御、回避、被弾、跳躍、死亡
- 元の動物の頭と顎の相対位置を数値で保存して再取り付けする。表情・顎運動の接続を維持する
- 首元の毛、胸部の皮毛、前腕、すねは肌ではなく獣毛。軽装の上から毛色が分かるようにする

## 品質ゲート
1. 動物ソースの頭・顎・尾、元の狼の4つのpawを移植できる
2. 装備が胴体・肩の関節に追従し、浮かない。顎も頭部について動く
3. 6.5〜7頭身を**最終目標**とする。今回は二足の身体構造・動作・輪郭を検証する試作品であり、実写相当の毛密度や顔の最終承認ではない
4. 低詳細・高詳細で3Dメッシュに非数値頂点や崩れがない
5. 通常の四足モンスター50種、召喚獣57種の契約とバトルは従来のまま
6. m005、m006はモデル編集・コード変更・検証対象にしない

## 確認手順
図鑑 `monster-manager.html?monster=m001&form=beastfolk` を開く。
「⚙ 設定」→「獣系モデルの姿」→「元の四足型／獣人型・二足（試作）」を切り替える。
`?monster=m002&form=beastfolk` と `?monster=m003&form=beastfolk` で他の試作に直接移動できる。
「顔・衣装」で頭蓋/顎/目/毛を点検し、画面下の待機・歩行・走行・攻撃・威嚇で独立した足と顎を確認する。

## 後続回帰
獣人型の顔、目、毛のボリューム、胴体輪郭を2D基準画と3D比較で追い込み、その後m004と猫科m007〜m010に適用。犬モデルが独立追加された場合は犬型固有パーツへ変更する。元四足モデルを置換・破棄しない。
