# 内装設計書 v29.0 — 灰銀のレゾナンス

## 目的と適用範囲
住宅設計図 `docs/HOUSE_BLUEPRINT_V28.md` の間取り、中央廊下、扉、階段を固定し、家具と生活小物を意味のある位置に配置する。建物サイズに応じて座標を比例させる。旧室内モデルを無秩序に復活させない。

## 共通レイアウト
室内幅 w、奥行 d、中心 (0,0)、奥側 z<0、玄関側 z>0。中央廊下は |x|≤4.8 のため家具を置かない。各部屋の扉付近 z=-0.29d / +0.19d、x=±4.8 には家具・小物を置かない。階段は左側（x=-w/2+4.1、z=.08d）。1階4室、2階4室。

## 1階：家具と小物
- 南西 リビング：3人掛けソファ（x=-.28w,z=.27d）、ローテーブル（-.30w,.05d）、低いテレビ台。ソファにはクッション。テーブルに書籍と陶器のマグ。ラグは家具群の下。
- 南東 ダイニング：ダイニングテーブル（+.30w,+.24d）と椅子。卓上に皿、マグ、中央の花瓶。東壁沿いにキッチンカウンター（+.37w,-.02d）を置き、ケトル・まな板を載せる。
- 北西 洗面収納：引き出し収納（-.31w,-.29d）、棚にタオルや瓶。壁際に照明。
- 北東 客間：ベッド（+.30w,-.30d）に掛布団と枕、壁際に観葉植物と絵画。

## 2階：家具と小物
- 南西 主寝室：ダブルベッド（-.29w,+.23d）とナイトテーブル（-.39w,+.34d）。枕2つ、サイドの本とランプ。
- 南東 子供部屋：シングルベッド（+.29w,+.24d）、勉強机（+.36w,+.35d）。机の上に本、卓上灯、文房具。
- 北西 書斎：デスク（-.31w,-.29d）、棚（-.40w,-.38d）。PC、書籍、机上灯。
- 北東 納戸：収納棚（+.33w,-.29d）。棚の内部には収納ケースと箱。

## 美術仕様
- 木材：落ち着いたウォルナット系と明るいオーク系を統一。
- 布：ベージュ、グレージュ、くすみ青。陶器はアイボリー系。
- テーブルや棚の上に小物を親子関係で配置し、床へ不自然に浮かせない。
- 遠方から見ても家具と分かるシルエット（脚、背もたれ、取っ手、クッション）を優先。
- 小物は衝突判定なし。大物・中物は表示サイズに合わせた衝突矩形。
- モバイルを考慮し、細かい造形の追加数に上限を設ける。

## 品質基準
1. 家具が廊下・ドア・階段を塞がない。
2. 小物は家具の上に載り、宙に浮かない。
3. 家具は部屋の用途に対応している。
4. 扉操作、1階2階切替、壁の非二重化が維持される。
5. 実在の外部3D素材を導入する場合、ライセンスと容量を確認する。今回の内装オブジェクトは手続き生成の改良版であり外部高精細モデルを導入したものではない。
