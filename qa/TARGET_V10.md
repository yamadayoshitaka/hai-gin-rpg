# 灰銀のレゾナンス — v10 ゴールデンリファレンス品質基準

基準：ユーザーが提示した理想画像（宿屋の外観＋宿屋の室内の2分割コンセプト）。
この画像は**美術的な目標**であり、ゲームからの実測スクリーンショットではない。写真のピクセル一致を要求しない。
現行の自動QA（qa/capture.cjs）は起動・構造・画面の一様性・床抜け等の**機械的回帰検出**であり、美術完成度を証明しない。

## 0. 品質ゲート

- **P0 / 必須・自動**：ロード完了、pageerror なし、WebGLキャンバスあり、モデル座標が有限、明白な床抜けなし、屋内外10視点の撮影完了。
- **P1 / 必須・画像レビュー**：建物のシルエット・屋根・窓・入口の自然さ。浮遊物体、意図しない貫通、家具の極端な重複、通路を塞ぐ家具がない。特に屋根の一体感を確認。
- **P2 / アート目標**：世界観・配色・環境密度・照明・遠景を理想画像に近づける。
- **P3 / 実機**：Androidで起動・移動・入退室・回転カメラ・会話・フレームレートを確認。Web版のスクリーンショット合格のみでは代替できない。

## 1. 屋外：宿屋（house index 8）

- [ ] 石＋木梁を基調とした一貫したファサード
- [ ] 実際の傾斜屋根と連続した軒。タイル、破風、煙突に重複・浮遊・突き抜けがない
- [ ] 2階の窓・雨戸・花箱・バルコニーの寸法と左右の整列
- [ ] 宿屋と分かる入口、看板、灯り、階段・玄関アプローチ
- [ ] 樽・箱・植木・花・市場小物は入口と歩行通路を塞がない
- [ ] 壁の材質が「一枚の大きな箱」に見えないスケールで描画
- [ ] 近景・中景・遠景の3段階の空間構成
- [ ] 地面は石畳が主役、建物まわりの草・土と自然につながる

## 2. 室内：宿屋（room index 8）

- [ ] 木目のある床と室内壁、木梁の構造
- [ ] 受付／食堂／談話席／客室への動線を区分した平面計画
- [ ] カウンター、棚、瓶・皿・本・ランタン等に用途がある
- [ ] 家具が大きな空間にばらばらに浮いて見えない
- [ ] テーブルと椅子の正面が合う。椅子は実際に座れる間隔
- [ ] 絨毯は床より上・家具より下。家具グループに合った色と大きさ
- [ ] 暖色光、暖炉や壁灯を基準に陰影・読める明るさ
- [ ] 仕切りや壁をカメラが貫通しない。プレイヤーと家具が衝突しない
- [ ] 階段・2階回廊などは**実際に歩けるときだけ**追加し、見せかけの通路を作らない

## 3. 町全体：その他

- [ ] 武器屋：鍛冶炉・武器ラック・重い木と石。売り場と工房が区別可能
- [ ] 道具屋：商品棚、瓶・袋、会計カウンター、店先の庇
- [ ] 教会：縦長窓、祭壇、長椅子、中央通路。石壁と赤系ラグ
- [ ] 民家：ベッド、食卓、収納。収納／就寝／談話のゾーンを整理
- [ ] 景観：看板・橋・木柵・街灯・植栽・街道・丘・森の連続性
- [ ] 近景・遠景のLOD／InstancedMeshでAndroid負荷を抑える
- [ ] 道・建物・NPC・家具の当たり判定を保持

## 4. 回帰撮影

- 屋外：`?qaShot=0,2,5,8,9,11` の各固定カメラ
- 室内：`?qaIndoor=0,2,8,10` の各固定カメラ
- 自動：`qa/capture.cjs` → `qa-screenshots/*.png` と `report.json`
- 画像の自動チェックは「空白／エラー／床抜け」の限定的な検査。**美術的合否は画像を実際にレビューする**。
- 変更のたびに **屋外宿屋 index 8 + 室内宿屋 index 8** を前後比較し、別の9視点も確認する。
- 前後画像の撮影はゲームのバージョンとコミットSHAにひもづける。モデルを追加した「予定」と実際に読み込まれた「実績」を区別。

## 5. 実装順（依存順）

1. 屋根・壁・窓・バルコニー等の形状、寸法、色とテクスチャを統一
2. 宿屋内装の実際の部屋割り、用途別家具、動線と衝突
3. 宿屋周辺の石畳・花箱・樽・小道具・街灯
4. 町の遠景（樹木・丘・建物の高低差・背景）
5. 照明・色調とゲーム内カメラを調整
6. 他建物への展開
7. 10視点の自動回帰＋Android実機の最終確認

## 6. 素材導入規則

候補：Quaternius Medieval Village MegaKit（建物）、Fantasy Props MegaKit（家具と小物）、Stylized Nature MegaKit（植栽）、Poly Haven（石畳・木床）。
- ライセンス・配信URLを確認。**ダウンロードを試みた**ことと**実際に読み込めた**ことを区別。
- 追加モデルは既存の見た目と衝突しない寸法で設置。モデルの読み込み失敗時は安定したフォールバックを残す。
- 同じ建物に複数屋根を重ねない。目視の前にバウンディングボックス、向き、マテリアルを確認。
- Android向けに過度な4K/8Kテクスチャを避け、低・中負荷で比較。
